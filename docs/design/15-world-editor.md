## 边界

世界编辑器是贯穿开发周期的唯一长期人工创作与调试环境，以普通存档中的世界为工作对象。本文定义它的工作区、创作工具交互和运行诊断。

## 不变量

- 编辑器面板、控制台、自动验证和 Godot MCP 都使用正式领域入口，不各自维护一套世界，也不绕过校验。
- 相机、选择、面板、辅助图层与模拟控制相互独立。选择不移动镜头，观察操作不改变权威状态，也不隐式暂停模拟。
- 预览和草稿不写入世界；提交时按当前世界重新校验，失败时不部分写入。
- 诊断只读取正式状态；修复、停车等修改仍走正式操作。

## 规则

### 工作区、选择与输入

工作区按职责分为工具与内容库、世界视图和对象检查器；工具包括地形／体素、建筑、铁路、车辆与运行计划。当前存档、未保存状态及模拟控制保持可见，操作结果与控制台可以展开。控制台承担精确参数和批量操作，与面板调用同一套正式逻辑，结果可追查；新增或修改正式命令时同步维护 [console 手册](../console/README.md)。

通常点选完整建筑、车辆或轨段，需要修改内部时显式进入该对象的局部编辑；世界体素用独立工具。界面显示当前层级、所属对象、目标身份和坐标系，可以返回整体。编组及运行计划从明确选中的列车进入，点选不自动聚焦或跟随。

支持视图框选和列表多选，列出数量、类型和身份，只提供共同支持的操作。同类批量操作整体校验，整体提交或拒绝；建筑、铁路和车辆混选时不套用同一个自由拖动。已有草稿绑定明确的目标集合，选择变化不改写目标，对象消失也不换成其他对象。

左键按当前工具选择、放置或绘制；右键拖动只用于观察，WASD/QE 仅在世界视图获得输入时移动相机。文本框、面板和控制台消费自身输入，不同时触发世界修改或相机移动；失焦、松键及控制台打开后，拖动按既有规则结束。聚焦和跟随须显式触发。有草稿时切换工具、层级或目标，须先明确提交或放弃，不静默丢弃。

### 工作平面与提交反馈

工作平面可见且可调整：默认水平面可指定高度，也支持竖直平面或拾取对象表面，并显示轴向、网格、吸附点和坐标。世界坐标与对象局部坐标明确区分，没有地形的空白世界也能定位。体素遵守整数格和定义允许的正交朝向；连续铁路使用自身的几何控制与合法接续吸附，不折成体素阶梯。

竖直平面垂直于 X 或 Z 轴，整数位置直接指定该轴的目标格层，与水平面高度的规则相同。拾取子格碰撞盒的面时，添加目标仍是命中体素整格沿面法线的相邻格。没有碰撞形状的体素不能作为拾取表面，可通过工作平面或精确坐标编辑。当前笔刷和长方体仅支持水平工作平面，选择这两种模式时切回水平面并锁定平面选择；返回单格模式后可重新选择其他平面。

鼠标位置、方向或范围与检查器中的精确参数共用同一份预览。建筑放置、整体移动旋转、铁路施工和批量改装在明确确认后才提交；体素笔刷以一次笔划为单位，结束后整体校验并提交；大范围或多步骤编辑先预览再确认。连续拖动和每次键入不直接提交。提交失败时指出具体冲突，并保留可调整的草稿。

单格体素工具中的定义、朝向和添加／移除／替换属于工具设置，修改后悬停预览继续跟随鼠标，不产生草稿。手动填写坐标以及提交被拒绝后保留的内容才属于草稿，目标保持到明确提交或放弃；离开世界时只能放弃草稿或取消离开，想提交须先取消并返回编辑。替换的定义和朝向都未变化时拒绝；有变化时新建体素，耐久恢复为新定义的最大值，原脱落零件身份不保留。

笔刷和长方体区域区分覆盖格与受影响格：添加跳过已有普通体素，移除跳过空格，替换跳过空格及定义、朝向都不变的普通体素；预览显示完整覆盖范围、受影响数、跳过数及全部冲突格。覆盖范围中的铁路或车辆占用、越界、未知定义和不允许的朝向均整体拒绝，没有受影响格也拒绝。提交时重新检查完整覆盖范围，把受影响格编码为一次 `voxel.cell-set`，作为一条正式输入和一条撤销记录。

当前水平笔刷为一格厚的 N×N 方形，以鼠标格为中心；偶数边长向负轴多覆盖一格。按住左键累计覆盖格，松开后提交，中断后保留为同一份可提交或放弃的草稿。已有笔刷草稿可由检查器精确坐标整体平移，保持累计形状与全部格；修改定义、朝向或操作也保持几何，草稿撤销／重做可恢复这些修改。要重新绘制另一条路径，先在提示中放弃旧草稿。长方体使用工作平面上的两个含端点的角和向上的格数高度，检查器可修改同一预览的两角与高度。当前暂定边长上限 16、覆盖格上限 4096、受影响格超过 512 时显式确认，常量位于 `VoxelRegionLimits`；超限明确拒绝，后续规模实测可调整这些限制。

### 各类创作工具

排期体素区域编辑在接受时固定受影响格列表；未来执行时逐格复核，任一格不再适用就整笔拒绝，不按执行时状态重新筛选。

| 工具 | 行为 |
| --- | --- |
| 地形／世界体素 | 单格、笔刷及长方体区域的添加、移除、替换；从有效内容中选择定义与允许朝向，预览准确的范围、数量和冲突。普通地形工具不能隐式拆散建筑、车辆或铁路所属的体素，须进入相应对象工具或使用显式伤害操作。保留精确坐标及跨高度编辑。 |
| 建筑 | 模板放置，整体移动、旋转、复制、删除，以及内部部件改装。合法的移动和旋转保留身份和状态；复制当前实例状态并分配新身份，不自动修复损伤。删除移除指定对象，伤害形成正式受损状态，两者分开。站点及其他引用受到的影响须明确显示并整体验证，不隐式移动相连的轨道、列车或删除外部引用；改装、损伤与完整修复遵守[建筑契约](https://github.com/odradekk/train/blob/329a0a2/docs/design/03-vehicles-buildings-and-designs.md#本阶段静态建筑契约)。 |
| 新建铁路 | 指定起点、终点、方向和高度约束，用中间控制点表达走向；精确参数与线路预览同步，显示线路、实际占格、净空和失败原因。水平道岔使用专用工具。没有合规结果时保留草稿。 |
| 既有铁路 | 改线、拆除、伤害、修复四类操作分开提供。改线时预览替换范围、接续端点和影响；拆除时显示涉及的轨段与连接。 |
| 车辆与编组 | 选择模板、既有车辆或完整编组，在轨道上指定位置和朝向，预览整列姿态、接触点、车钩与净空。制造、连接／解编、起停和换端分别提供入口；离轨设计和部件试装由蓝图创作流程承担。 |
| 站点与运行计划 | 从实际站点建筑查看接轨接口及整列停车空间。选中编组后编辑单次或循环站序、停留时长和换端许可，草稿可随时修改。 |

后四类工具的提交条件和拒绝规则见 [06 的编辑器中的铁路与车辆修改](https://github.com/odradekk/train/blob/62c40d2/docs/design/06-railway.md#编辑器中的铁路与车辆修改)。铁路几何、换端、通行保护及故障恢复遵守[铁路契约](06-railway.md)，工具不放宽这些规则。

### 运行诊断

#### 统一诊断与关联定位

编辑器提供统一的诊断工作区，从检查器进入对象状态、命令记录、铁路运行关系及复现资料。错误条目可定位相关的对象、轨段或位置；目标已失效时保留原身份和事件信息，不自动替换成其他对象。选择条目不移动镜头。

辅助图层按用途独立开关，分别显示体素实体占格、碰撞、车辆实际占用、线路净空、通行预留／道岔锁，以及 Chunk、视觉驻留和渲染原点，并提供图例与对应的模拟位置。默认围绕所选对象或指定区域；只显示局部或尚无数据时明确标出，不能把未显示当作没有冲突。轨道实体占格、车辆实际占用和未来路径预留分别显示，不混为一个“占用”字段。

#### 有限条件暂停

除运行、暂停和精确步进外，还提供有限的“运行到条件”：指定模拟步，或指定命令被拒绝、指定对象发生故障等已支持的事件。用户显式启用后，在完整提交边界暂停并说明命中原因；可以取消，也可以设置最大推进步数，未命中时如实结束。这些操作实际推进当前世界并保留结果，不自动回退。

条件绑定启用时明确指定的命令或对象的稳定身份，只匹配启用之后发生的正式事件，选择变化不换目标。指定命令已结束、目标已失效或指定步已过去时，提示无法再等待，不自动重试或寻找替代目标。运行期间目标失效、达到步数上限、用户取消或命中条件，都在完整边界停止并显示各自的原因。条件设置只属于本次调试会话，不进入普通存档，切换世界时清除。

#### 命令记录与故障反馈

命令记录区分提交前拒绝、待执行、执行成功、执行时拒绝和内部故障，显示操作来源、目标、参数、接受／计划／实际执行位置及结果原因。可以按对象、类型和结果筛选，并定位关联条目。解析或入队前就被拒绝的操作不伪造已接受命令的编号；执行时被拒绝的命令按原顺序出队，后续命令继续。界面标明显示范围及截断情况：有限日志不冒充完整录制，已接受不冒充已执行成功。

反馈分三类：

- 普通拒绝：解释原因，默认不暂停。
- 世界内可恢复的故障（如断轨、建筑失效）：显示正式修复和显式恢复所需的条件，不偷偷修复或清除保护。
- 内部异常或不变量破坏：突出显示会话已冻结、最后完整边界及证据入口，保留查询和诊断导出，不能用“继续”按钮强行清除；须加载已知有效状态或重建会话才能继续工作。

条件暂停只用于观察，不改变上述领域语义。

#### 录制状态与检查点

默认有界录制提供常驻摘要及可展开面板，显示录制状态（正在录制、不完整、尚无可用起点）、实际可复现范围、容量占用和最近错误，并可从事件或命令定位对应记录。用户可以在完整边界添加说明标记；标记不改变世界，也不让历史永久保留。旧记录即将被裁剪或已不在完整窗口内时明确提示；只有实际保留的起点、输入与依赖齐全时，才显示可完整复现。

权威检查点支持人工打点，也支持正式验证序列自动打点，都在完整事务边界捕获；显示模拟位置、输入位置、来源、内容和构建信息，可导出规范状态与摘要。比较时先说明环境、来源和输入是否可比，再定位最早可比较的检查点、对象、字段及预期值与实际值。内容适配与环境不一致单独列出，不冒充确定性缺陷；不同人工操作后的状态差异可用于排查，但不能据此宣称同输入复现失败。

导出默认包含当前完整录制窗口，也可以选中事件或完整边界作为终点，自动带入此前可用的恢复起点及到终点所需的全部输入、内容与依赖，并预览实际范围；不能从任意日志行开始拼成完整复现。导出开始后固定本次资料，当前世界可以继续运行，后续变化不混入包。记录不全时说明缺口，只能作为不完整诊断资料导出。导出失败或取消时保留已有目标文件，覆盖已有包须明确确认。

#### 故障片段与隔离重放

保留故障片段的留存与离开处理、隔离重放模式的打开与停止，以及从有效边界建立普通编辑副本，核心规则见 [04](04-deterministic-simulation.md#录制与复现)。重放界面持续显示复现包身份、记录位置及重放状态；播放结果、检查点对照与人工结论分别呈现。

#### 录制输入与回归案例

录制以正式操作、明确目标及实际结果为主。世界修改、运行输入、撤销／重做和内容发布尝试按正式边界记录；发布须保留重放所需的候选内容及依赖，不能只记文件路径。相机、选择、图层及渲染原点信息与领域输入分开记录，用于排查显示问题，不参与世界仲裁。未提交的创作草稿、表单输入和文件读写失败可以作为附属诊断资料，但不作为领域重放已验证的证据。

人工探索可以从完整起点及正式操作序列整理成案例草稿，由开发者写明规则、预期结果和必要检查点，不能直接把录制到的结果当作测试预期。缺陷案例优先保留原始故障资料，回归测试另行断言修复后的正确行为；不把每次鼠标操作或整段探索机械地转成永久测试。

#### 自动化与工具边界

自动化和 Godot MCP 是正式能力的使用者，不另建世界修改路径；具体操作经过正式命令或调试接口，不能直接改节点位置或内存来冒充领域操作。截图、日志及启动成功都只证明各自实际观察到的范围。

#### 性能概况与详细采样

轻量运行概况显示模拟是否跟上、帧耗时与模拟耗时、内存与对象数量等已可测指标；详细追踪、较大范围的图层和完整状态抓取由用户按需开启。记录采样范围、开关与采样自身的开销；缺失的指标显示为未采集，不能用零值代替。编辑器的即时统计用于定位问题，不自动成为 Benchmark 通过证据；默认录制的成本计入正式性能验收，见 [00 的本阶段性能目标](00-product-and-core-loop.md#本阶段性能目标)。

## Demo 范围

世界编辑器是开发工具，不是 Demo 中面向玩家的内容。本阶段提供：工作区与输入、工作平面与提交反馈、上表六类创作工具、有限撤销、统一诊断与辅助图层、有限条件暂停、命令记录与故障反馈、录制状态与检查点、故障片段与隔离重放、性能概况。

## Demo 之后

以下能力不在本阶段提供，也不是 Demo 的前提，确有需求时再选入：平滑、侵蚀、任意形状选区等高级地形工具；任意跨类型的联合改造；任意脚本断点和完整的时间倒带；自动重放所有 GUI 手势或磁盘故障；崩溃后自动恢复故障片段；默认每帧抓取完整状态。
