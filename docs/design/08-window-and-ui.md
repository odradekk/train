# 08 窗口与界面

> **所属层**：渲染层。

> 决策出处：主窗口、宏观地图、场景切换、管理界面、通知、常驻控件和各视图的相机，由[窗口与界面的设计和规划](https://github.com/odradekk/train/issues/207)于 2026-10-05 确认。它取代了桌面停靠（Bottom Dock、Windows AppBar、Floating）、辅助窗口等规则；桌面停靠已由[产品定位、玩法支柱与 Demo 范围](https://github.com/odradekk/train/issues/194)从产品规划中删除，[桌面停靠研究](../research/desktop-dock-window.md)只作历史资料。模拟与窗口状态解耦、最小化时停止渲染、渲染帧率上限、线路场景的相机跟随规则，沿用转录 Q154–Q165 与 [#30](https://github.com/odradekk/train/issues/30)。画质两档由[Compatibility 渲染器下的画面目标](https://github.com/odradekk/train/issues/242)确定，没有铁轨的线路的画法和列车的状态由[美术文档的整体一致性检查](https://github.com/odradekk/train/issues/253)于 2026-10-09 确认，镜头抖动开关由[磨损、损伤、动画与特效](https://github.com/odradekk/train/issues/251)于 2026-10-09 确认。

## 不变量

- 模拟与窗口状态严格解耦：失焦、被遮挡、最小化、打开普通面板都不停止模拟。玩家暂停、内部故障，以及[跨层协议](../contracts/transactions.md#技术操作锁与线程)规定的技术操作锁是停止驱动的明确情况；不能把普通场景加载混入技术锁。
- 宏观地图和管理界面通过核心模拟层的只读查询读取数据，不经过体素引擎层，也不拥有独立的世界状态。
- 界面上的操作都作为命令提交给核心模拟层；打开面板、切换视图不是命令。
- 管理界面是同一份核心状态的视图，不隐式改变地图或场景的视角（转录 Q165）。

## 规则

### 主窗口

- 游戏使用普通游戏窗口，支持窗口化、无边框全屏和独占全屏。
- 主菜单包括新游戏（按种子生成世界）、读档、设置和退出。读档或新开一局后，默认暂停并显示宏观地图，由玩家开始运行；默认开局与开放沙盒的目标、结束规则见 [00](00-product-and-core-loop.md#目标与一局结束)。开发构建的主菜单另有“从示例开始”；创作模式和调试模式也只在开发构建中提供，见 [15](15-design-editor-and-tools.md)。
- 失焦和被遮挡时照常模拟、照常渲染，不专门检测遮挡。最小化时照常模拟，但停止渲染，恢复后继续渲染。设置中提供“失焦时自动暂停”，默认关闭。画质分“中”“高”两档，见[美术 05](../art/05-lighting-and-readability.md#效果清单)。
- 启用失焦自动暂停后，重新聚焦只解除失焦造成的暂停；玩家手动暂停、通知暂停、编辑暂停和技术操作锁仍各自有效。没有其他暂停原因时按当前倍速继续，不追赶失焦期间的时间。
- 提供可配置的渲染帧率上限，默认值由性能测试确定。限帧与窗口状态不改变模拟时间的推进规则。
- 关闭窗口就是退出游戏。有未保存的进度时提示保存；Demo 提供自动存档，间隔、轮换与关闭设置遵循 [09](09-persistence.md#自动存档)。游戏关闭时世界不运行，没有离线进度。

### 宏观地图

- 宏观地图是 2D 俯视地图，可以平移和缩放。
- 底图按节点的地貌概况划分区域并着色（类似 Voronoi 分区），只使用节点和线路的地貌概况，不需要额外保存栅格，也不调用生成器的噪声函数。以后如果需要更细的底图，再改为生成时另存一张粗分辨率栅格。
- 常驻的信息：
  - **节点**：占据者图标；聚居地按关系着色，分为自有、非敌对、敌对；
  - **线路**：用平行线的条数表示铁轨数，没有铁轨的线路画成虚线，并标出断点和施工中的线路，画法见[美术 07](../art/07-icons-and-ui.md#宏观地图)；
  - **列车**：沿线路移动的图标，按状态区分：运行、装卸、等待（在节点排队或按停车命令停着）、受阻（没有可达路径）；Demo 加战斗（含撤退）。颜色见[美术 07](../art/07-icons-and-ui.md#状态色)；
  - **战斗**：进行中的战斗标记。
- 可以开关的信息层：节点资源、世界生物、站台占用。

### 场景切换

- 宏观地图是中心。从地图上点节点进入节点场景；点线路或列车进入线路场景，默认跟随这列车；从菜单或车辆面板进入设计编辑器。
- 同一时间只显示一个场景。场景打开时隐藏宏观地图，按返回键回到地图。
- 普通地图打开场景时不显示阻挡操作的全屏遮罩，模拟照常运行；首个可操作状态要求焦点目标和近处操作区已显示、可业务拾取且输入实际响应，只有地形或相机响应不算。未加载地形以雾表示且不可拾取，远处在首个可操作状态后 5 秒内补齐；显示范围 Ready 时外圈仍可有雾。节点范围值为暂定，见 [01](01-voxel-engine-and-scenes.md#场景的存储与构建)，实测后由用户确认。构建失败时留在地图并提示原因。跟随列车时的场景切换仍无缝且不显示遮罩，见 [01](01-voxel-engine-and-scenes.md#跟随列车时的场景切换)。
- 发生战斗时发出通知，玩家点击通知可以进入该地点的场景观战。
- 跟随列车时，场景随列车所在地点自动切换，见 [01](01-voxel-engine-and-scenes.md#跟随列车时的场景切换)。

读档、重放或内容发布替换活动绑定时，旧场景拾取与面板绑定同时失效；新表现未就绪则明确显示加载状态，不继续操作旧世界。提交后的场景／引擎资源故障不回滚权威状态，不能静默显示替代内容冒充成功，见[场景接入](../contracts/transactions.md#场景接入与资源退役)。

世界场景或其运行资源失败时退出该场景、返回宏观地图并提示原因，玩家可重新打开；不因此暂停正常核心。编辑场景失败时保留草稿及保存、退出入口，停用场景编辑并提供重试，编辑暂停仍有效。两种情况都不自动反复重试，也不回滚已经成功提交的世界或内容；诊断同时进入游戏界面和控制台。

### 管理界面

- 管理界面都是同一个游戏窗口里的面板，不开独立的系统窗口。可以同时打开多个面板，面板盖在地图或场景之上。
- Demo 的主要界面：
  - **车队**：列车列表、编组、运行计划（停靠站、途经点、停留时长、单次或循环）、交易规则；
  - **线路与施工**：扩建、新建、修复线路，材料来源，自动修复；
  - **聚居地**：地块与建筑、建造与工地、生产、库存、人口、站台；
  - **市场**；
  - **服务**：在非敌对聚居地委托建造、改装、修理车辆，以及仓库租用；
  - **战斗**：交战规则、战报；战报只在本次运行中保存，不进存档，见 [17](17-combat.md#记录与事件)；
  - **报告**：运行报告、经营报告；
  - **通知记录**；
  - **设置与存档**。
- 面板中选中的对象被摧毁时，面板显示“已不存在”，不自动换成别的对象。
- 聚居地人口、劳动力、各项需求满足率和人口趋势读取 [18 的核心查询](18-population-and-labor.md#权威状态查询与事件)，不在界面重算；建城前显示初始人口与预计生活物资需求。人口规则缺失须显示不可用原因，不能当成普通短缺。
- 物品图标由内容中的图标图片加界面统一绘制的外框组成；大型设备等复合体货物的图标按设计自动渲染：Godot 用体素引擎层给出的设计网格在离屏视口里渲染，按设计哈希和内容世代缓存在内存里，不写入存档或磁盘（[资产访问与导入](https://github.com/odradekk/train/issues/286)）；地图、面板、字体、状态色和图标的视觉规则见[美术 07](../art/07-icons-and-ui.md)，由[宏观地图、界面与图标的视觉风格](https://github.com/odradekk/train/issues/244)于 2026-10-09 确认。
- 每个界面的具体布局和信息结构，在代码重构后先做流程原型再定，见下文开放问题。

### 通知

- 核心模拟层发出的、面向玩家通知的领域事件，在界面上显示为短暂提示，同时进入通知记录；点击可以跳到相关对象。人口每期结算摘要进入经营报告，不每期弹通知；短缺开始、恢复和降至最低人口等状态变化才通知，见 [18](18-population-and-labor.md#权威状态查询与事件)。
- 事件按重要程度分为信息、完成、警告、严重四级，例如建筑被摧毁高于委托完工；颜色见[美术 07](../art/07-icons-and-ui.md#状态色)。
- 每类事件可以设为“发生时暂停”或“发生时降到 1×”。这些是界面设置，不是命令；默认都关闭，只有遇敌默认降到 1×。
- 宿主每完成一个模拟步就按顺序处理该步事件，先落实暂停或降速，再决定是否继续本帧推进；不能先完成整帧多步才响应。同一步内暂停优先于降速，降速不解除已有暂停；停止使用原倍速剩余的整步额度，不形成之后追赶的时间债务。命令产生的事件同样在该命令完成后处理。

### 常驻控件

- 顶栏放倍速控件（暂停、1×、2×、4×、8×），旁边显示实际速度，并显示游戏内时间和资金。
- 游戏内时间就是模拟时间（模拟步数 ÷ 60 秒），显示为天、时、分；不另设日历。
- 复现包的导出入口放在设置菜单中的“报告问题”，见 [04 的录制与复现](04-deterministic-simulation.md#录制与复现)。
- 场景中车辆和建筑的血条、状态图标默认在悬停或选中时显示，也可以设为一直显示。

### 相机

- **宏观地图**：正交相机，平移和缩放。
- **节点场景**：围绕聚居地的环绕相机，可以 360° 水平转动，俯仰角受限，可以缩放，平移范围限制在场景内。点击建筑打开它的面板。
- **线路场景**：默认跟随一列车，也可以切换到沿线路的自由环绕，规则见下节。
- **战斗**：使用所在场景的相机，另外可以聚焦到某个单位。
- **设计编辑器**：环绕设计物，可以按高度剖切显示，见 [15](15-design-editor-and-tools.md#设计编辑器)。
- 透视相机的缩放只改变相机距离，FOV 基本固定。
- 节点相机最远距离暂定 240 格（120 米）、最低俯仰角暂定 0.15 弧度；显示半径外及前景可能仍可见雾，具体观感待用户确认。美术 far 视角超出暂定显示范围时也可能看到雾。
- 玩家正在看的对象被命中时，镜头小幅抖动。设置中提供“镜头抖动”开关，默认打开，见[美术 06](../art/06-wear-damage-and-motion.md#特效的强度上限)。

### 线路场景的相机跟随

- 相机朝向 = 所选车辆显示的车体朝向 + 玩家的环绕偏移。列车转弯时相机平滑跟随；玩家改变的是相对于所选车辆的观察位置。
- 相机读取 [07](07-rendering.md) 中与车体一致的显示位置和朝向，不直接跟随跳动的模拟步位置，也不用速度方向代替车体朝向。列车反向行驶时不自动把镜头转 180°。
- 玩家在同一列车的不同车辆之间切换观察目标时使用平滑过渡，不瞬间跳转。当前目标被摧毁时，回退到同一列车中的有效车辆，优先级在原型中确定。
- 不采用传统的第三人称弹簧臂，相机不因普通建筑或地形持续自动拉近拉远。以后如果遮挡问题明显，再考虑遮挡物淡出。

## Demo 范围

普通游戏窗口与全屏；2D 宏观地图与信息层；场景切换；窗口内面板形式的管理界面；通知与按事件暂停或降速；倍速控件；各视图的相机；最小化时停止渲染；可配置的渲染帧率上限。

## Demo 之后

专门的遮挡检测；生成时另存的地图底图栅格；行人等与数量对应的场景表现；托盘与后台模式（已从产品规划中删除，见 [00](00-product-and-core-loop.md)）。
