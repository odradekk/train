# 17 战斗、世界生物与征服

> **所属层**：核心模拟层；战斗的体素表现属于局部场景。

## 不变量

- 战斗只由核心模拟层结算。场景只表现战斗事件和核心中的损伤，不影响结果。
- 战斗内部没有距离和位置。一场战斗只有一个地点：某个节点，或某条线路上的某个位置；同一地点同一时间最多一场战斗。
- 敌我只由每两个参战者之间的关系决定，不设固定的两方或阵营。
- 同一步的全部命中作为一个伤害事件结算，结果不依赖遍历顺序。
- 战斗、生物行动和新聚落中的随机都使用无状态带键随机。

## 规则

### 参战单位与敌我

- 参战单位有三类：列车、聚居地的建筑和停放车辆、生物群。会攻击的只有装有完好武器部件的车辆和建筑，以及带 `weapon` 行为的生物。
- 每两个参战者之间按关系判断是否敌对：
  - 生物与所有非生物敌对，生物之间不互相攻击；
  - 玩家与敌对聚居地敌对；
  - 玩家与自有、非敌对聚居地友好，NPC 聚居地之间友好。
- Demo 中线路上只有玩家的列车，所以没有列车之间的战斗；规则本身允许任意两个敌对的单位交战。

### 开战与加入

- 两个互相敌对的单位处在同一地点，就开战：
  - **线路上**：生物群和列车在同一条线路上，并且两步之间位置相遇或交叉，不论列车在哪条铁轨。战斗地点是相遇的位置。
  - **节点上**：例如生物群到达有聚居地的节点，玩家列车到达敌对聚居地或生物聚落，双方停在同一个空节点。
- 战斗进行中，到达该地点的单位自动加入：
  - 线路上，之后到达这个位置的列车加入，不论走哪条铁轨；同一铁轨上跟在参战列车后面停下排队的列车也算加入。
  - 节点上，该节点的全部列车、停放车辆和建筑都是参战者，都可能成为目标。
- 线路上进入战斗的列车按正常制动减速度停下，生物群原地停下。战斗内部没有距离，所以制动距离不影响结果。
- 参战的列车和生物群不能离开，撤退除外。在站台装卸的列车也要等战斗结束。
- 战斗结束后，没有撤退的列车继续执行原计划。

### 结算

- 战斗按模拟步推进。每个完好的武器部件按自己的射击间隔开火，每只带 `weapon` 的生物按自己的攻击间隔攻击。每次射击或攻击都是一次命中，Demo 中必中。
- 每次射击依次：
  1. **选目标单位**：按射击者的交战规则，在攻击范围内的敌对参战者中选择；条件相同时按稳定 ID。集中攻击指令优先。
  2. **选落点**：目标是车辆或建筑时，用带键随机在结构和各个部件之间选一个，按体素数加权，结构按结构体素数计，每个部件计 1。例如 400 个结构体素、40 个引擎体素，结构被命中的概率约 91%。目标是生物群时，用带键随机选其中一只个体。
  3. **结算**：同一步的全部命中作为一个伤害事件，按 [03](03-vehicles-buildings-and-designs.md#损伤与战斗事件) 先统一施加，再判定哪些部件被毁、哪些单位被摧毁。超出部件剩余耐久的伤害作废，不溢出到结构。生物个体的生命值降到 0 即死亡，从生物群中移除。
- 随机键由战斗、步号、射击者和武器的部件编号组成；生物用个体身份代替部件编号。键布局和固定向量在实现时按 [04](04-deterministic-simulation.md#随机性) 补齐。
- 在 [Tick 流水线](04-deterministic-simulation.md#tick-流水线)中，射击在 Evaluate 中产生，伤害在损伤结算中施加；随后更新士气，判定投降和战斗结束。
- 没有任何参战者拥有完好的武器，并且在自己的攻击范围内找得到敌对目标时，战斗结束。已投降的聚居地不再攻击。战斗时长由双方的伤害和耐久决定，不另设上限。
- 被摧毁的车辆直接删除，车上的货物一起损失，不留残骸。被摧毁的建筑见 [16](16-settlements.md#地块与建筑)。

### 交战规则与战斗指令

- 每列列车有一份交战规则，每个聚居地有一份，后者只用于防御：
  - **目标优先级**：优先武装单位、优先耐久最低，或优先耐久最高；
  - **攻击范围**：只攻击武装单位，或攻击全部；
  - **遇敌行为**（只对列车）：交战，或立即撤退；
  - **撤退阈值**（只对列车）：结构耐久比例低于该值时自动撤退。
- 默认值：
  - 有武器的列车：交战，只攻击武装单位；
  - 没有武器的列车：遇敌即撤退；
  - 聚居地：攻击全部。
- 生物种类在内容中固定为攻击全部；撤退阈值由生物种类定义。
- 战斗中的指令有两种：撤退；集中攻击某个目标，持续到目标被毁或战斗结束。它们和设置交战规则、宣战、占领一样，都是普通命令，见 [04](04-deterministic-simulation.md#命令)。
- 护卫就是编组中的武装车辆。另一列武装列车跑相同的计划，到达战斗地点时按上文加入。Demo 不设“跟随某列车”的命令。

### 撤退

- 撤退的单位先经过一段脱离时间。这段时间里它不开火，但仍可能被攻击。
- 脱离后：
  - 在线路上，列车掉头开回出发的节点；同一铁轨上跟在后面的列车一起掉头，方式同 [06 的断轨](06-railway.md#断轨)。
  - 在节点上，列车开往按用时最近的自有或非敌对聚居地。
  - 列车到达后停车并发出事件，等玩家重新启动，避免它按原计划再次遭遇同一批敌人。
  - 生物群返回自己的聚落；失去聚落的生物群继续游荡。
- Demo 中生物不追击。

### 武器与防御建筑

- 武器是带 `weapon` 行为的单格体素或功能复合体（例如多格火炮），属于部件，见 [03](03-vehicles-buildings-and-designs.md#部件与结构)。WeaponBehavior 的参数是每次伤害和射击间隔。
- 单格武器是货物，由普通生产流程制造，见 [11](11-goods-and-production-network.md#武器)；多格武器是大型设备，在建造设施中按蓝图建造，见 [14](14-construction-refit-and-deconstruction.md)。
- 装有武器部件的建筑就是防御建筑，不另设建筑类型。
- Demo 中武器不消耗弹药。战斗与经济之间靠修理消耗货物联系起来。

### 世界生物

- **生物种类**由一份蓝图类别为生物的蓝图定义，蓝图上的行为给出数值：`creature` 给出生命值、移动速度、撤退阈值和袭击时长，`weapon` 给出每次伤害和攻击间隔，字段见[蓝图的格式](../content/blueprint.md#蓝图上的行为)。生物没有部件，不进设计编辑器。
- **生物群**由各有生命值的个体组成，可以混合多个生物种类，属于一个生物聚落。
- 生物群沿世界图的线路移动，不需要铁轨。位置记法与列车相同：在节点，或者在某条线路上的某个方向和距离。生物群不占铁轨，不受方向锁和跟车约束，速度取成员中最慢的。
- 生物群不进入 NPC 聚居地所在的节点，所以 NPC 聚居地不会遭到生物袭击。原因是 NPC 聚居地不自行重建，被毁的建筑会永久缺失。
- 生物群有三种行动：
  - **驻守**：留在聚落；
  - **游荡**：在离聚落若干跳的范围内，用带键随机走到相邻节点；
  - **袭击**：在范围内选一个玩家聚居地或有铁轨的线路，过去攻击，结束后返回聚落。

  出动频率和范围由聚落类型定义。
- **袭击聚居地**：到达节点即开战。袭击时长到期，或成员损失超过撤退阈值时，生物群撤退。
- **袭击线路**：生物群在线路上某个位置停留一段工作时间，然后在该位置给这条线路的每条铁轨各加一个断点，见 [06](06-railway.md#断轨)。这段时间里如果有列车到达，就按上文开战，袭击中断。普通战斗不产生断点。
- 击杀途中遇到的生物群没有奖励，奖励只来自清剿聚落。

### 生物聚落

- 生物聚落是节点的占据者，见 [05](05-world-graph-and-generation.md#节点)，并记录自己的聚落类型。聚落类型是内容定义，给出生物种类组成、生成间隔、成员上限、袭击频率与范围，以及清剿奖励。
- 留在聚落的生物群就是驻守部队。新生物按生成间隔补充进来，直到达到成员上限。
- **清剿**：节点上的战斗结束后，如果节点上已经没有生物，并且有玩家列车在场，聚落就被移除，节点变为空，奖励作为资金发给玩家。之后可以在该节点建立聚居地，见 [16](16-settlements.md#建立聚居地)。
- 聚落被清剿时在外的生物群失去归属，只游荡，不再袭击。
- **新聚落**：一个全局事件按内容设定的频率，用带键随机挑选一个不与玩家聚居地相邻的空节点，在那里生成新聚落。

### 聚居地关系与征服

- 聚居地关系分为玩家拥有、非敌对和敌对，只在三种情况下变化：
  - 生成世界时设定初始关系，见 [05](05-world-graph-and-generation.md#世界生成流程)；
  - 玩家用“宣战”命令，把一个非敌对聚居地变为敌对；
  - 征服后变为玩家拥有。

  Demo 中敌对不能变回非敌对，外交属于 Demo 之后的 AI 势力。
- **宣战**：玩家在该聚居地有进行中的委托，或有玩家车辆停在该节点时，宣战被拒绝。宣战后，玩家在当地的租用库存冻结，不能存取。
- **士气**：每个聚居地记录士气，范围 0–1，属于核心状态。
  - 受到伤害时下降，降幅为“伤害占该聚居地全部建筑耐久之和的比例”乘以一个系数；
  - 武器部件被毁时额外下降；
  - 节点上没有战斗时按一定速度恢复。

  Demo 中士气只用于 NPC 聚居地投降。玩家聚居地的士气同样变化，但不会投降。士气对生产、人口等方面的影响，在市场与人口规则中确定。
- **投降**：NPC 聚居地的士气低于阈值时投降，进入“已投降”状态，防御停火。士气恢复到阈值以上后，该状态解除，防御恢复开火。
- **占领**：同时满足以下条件时，玩家可以下“占领”命令，聚居地立即归玩家所有：
  - 节点上没有进行中的战斗；
  - 该敌对聚居地已投降，或者没有完好的武器部件；
  - 玩家有列车在这个节点。

  需要单独下命令，因为玩家可能只想打掉防御。没有防御的敌对聚居地，玩家列车到达后就可以占领。
- **易主**：地块、全部建筑（保持受损状态）、库存、电力池和人口都转给玩家。玩家在当地的租用库存中的货物并入该聚居地的库存，租约结束，已付的租金不退。
- Demo 中只会发生“玩家征服 NPC 聚居地”一种易主：
  - NPC 聚居地不自行施工，所以不会出现施工期间易主；
  - 生物不征服聚居地，玩家聚居地即使建筑全部被毁，仍归玩家所有，地块空出，可以重建。

  AI 势力加入后，易主怎样处理在那时再定。

### 记录与事件

- 战斗是核心状态中的对象，记录稳定 ID、地点、参战者和开始的步号，随存档保存。战斗进行时也可以存档。
- 领域事件包括：开战、射击与命中、部件被毁、单位被摧毁、撤退、投降、聚落被清剿、战斗结束。战斗结束事件附带一份摘要，包括各方损失和奖励。
- 战报由界面在本次运行中保存，不进存档，见 [08](08-window-and-ui.md#管理界面)。

### 场景中的战斗

- 战斗场景就是该地点的线路场景或节点场景，见 [ADR-0008](../adr/0008-simulate-the-world-in-a-voxel-free-core-and-build-voxel-scenes-as-presentation.md)。场景按战斗事件表现射击、命中和部件被毁，按结构耐久比例表现结构损伤，见 [01](01-voxel-engine-and-scenes.md#场景中的结构破损)。单位的摆放、射击和生物的表现见 [01](01-voxel-engine-and-scenes.md#战斗与世界生物的表现)。
- 单位在场景中怎样摆放只影响表现。

## Demo 范围

战斗的开始、加入与结算；交战规则、集中攻击与撤退；武器部件与防御建筑；生物种类、生物群与生物聚落，包括游荡、袭击、清剿和新聚落事件；宣战、士气、投降与占领。

## Demo 之后

战斗内部的距离、射程与阵型；命中率；弹药消耗；残骸与回收；“跟随某列车”的护卫命令；生物追击；列车之间的战斗与 AI 势力参与的易主；外交与停战；士气对生产和人口的影响。

## 开放问题

- 武器种类、伤害与射击间隔，生物种类与聚落类型，脱离时间、袭击工作时间、士气系数、投降阈值与恢复速度、新聚落频率和清剿奖励，都是内容数值，在试玩后冻结。
