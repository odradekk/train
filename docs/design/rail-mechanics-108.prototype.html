这次实验要回答：在两个等效接触点、刚性车体和统一固定长度车钩下，哪些线路与机械参数值得进入正式验证？观察真实三维转向与俯仰，再检查采样误差和失败位置。

首轮三维运动与停车换端观感已获确认；B 已接受为下一轮实验基准，坡度过渡按水平投影距离配置。机械范围与统一轨距已成为实施目标，最终线路、净空与误差门槛仍待确认。这里检查折线路径上的离散姿态与盒状车体，不证明连续扫掠安全、实体轨道占格、真实轮轨接触或正式 Godot 效果。不实现多列车调度。

首批机械范围 · 已采纳为实施目标

本轮修正线路位置积分为步内中点朝向：复测机械范围并补齐已批准默认机械配置的15类线路矩阵，共2,657项、107,425个范围内姿态采样通过；两个底高为零的范围外反例仍失败。细分前后的几何位置差最多约0.00072格，仍不构成连续误差上界证明。当前报告见 JSON 的 thirdRound；下文2,072项为第二轮历史记录。

前、后悬伸各自 0.5–2 格，车底高 0.5–1 格；轴距等于声明档位的包络长度减去两端悬伸。五档共用连接长 1 格、安装高 1 格、三维车钩夹角上限 15°。安装高从首轮 0.5 调到 1，使接口不会低于候选范围内的车体底面；这项调整及机械范围已获确认，轨距固定为两条轮轨参考线之间 1.5 格。

四类重点线路覆盖逐车不同边界配置；弯中坡谷另查五档有序双车的全部 8×8 个机械角点组合。每车 8 个角点来自前悬、后悬、底高各取上下界。另对最紧张的已测结果加密，并保留底高为零的侵轨反例。范围内共 2,072 项、69,400 个姿态通过；另两个底高为零的反例失败。已测最大钩角约 7.53°，最小底部余量约 0.424 格。完整记录在随附 JSON 的 rangeExperiments / rangeRefinement；这些实验不证明整个连续范围。

判断边界

  • 运行推进失败：停在最后有效姿态并报告；手动定位可显示不可运行的失败检查姿态。求解失败不等于数学上已证明无解。
  • 当前误差候选：距离 10⁻⁵ 格，净空/交叠容差 10⁻⁴ 格；不是正式产品阈值。
  • 车体按完整盒包络检查，轨道与轮组是示意。
  • 水平道岔仅验证公共端与直向/分支的单条路径；这里不模拟尖轨、信号和联锁。
  • 原型采样通过后，首轮观感已确认；机械范围已采纳为实施目标，并须完成正式领域、连续扫掠、损伤、存档和 Godot 验证。
