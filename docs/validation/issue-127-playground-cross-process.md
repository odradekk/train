# Playground 跨进程对照（#127）

此入口消费 `PlaygroundConfigurations.StraightRailTrainId` 与独立的正式序列
`PlaygroundSequences.CrossProcessComparisonId`。固定配置只建立初始世界；序列负责输入和断言。
脚本先用四个独立 Godot 进程执行连续、保存退出、恢复继续、观察干扰，再运行失败保护和两种故障注入。
每次运行创建新的输出目录和四组独立用户数据，不读取旧报告。脚本拒绝已经存在的输出目录。

```powershell
$env:GODOT = 'D:\Godot_v4.7.2-stable_mono_win64\Godot_v4.7.2-stable_mono_win64_console.exe'
dotnet build Train.csproj
& $env:GODOT --headless --path . --editor --import
pwsh -NoProfile -File scripts/run-godot-playground-cross-process.ps1
```

若指定 `-OutputDirectory`，须给尚不存在的路径。`report.md` 记录受测提交、构建/内容摘要、配置、环境、
领域、真实 Godot、跨进程、人工四栏结果及未验证项；`config.json`、`processes.log`、原始 stdout/stderr、
`evidence/00–12-evidence.json`、负例证据和隔离存档留在同一目录。检查点 8 是模拟步 0 的第 8 个操作位置，
保存四条待执行输入；恢复在该位置比较后继续。检查点 9 处理失效输入并执行后续独立输入。
比较复用 `AuthorityCodec` 和 `AuthorityComparison`：来源、构建和语义内容先核验，然后核验检查点输入、
模拟步与步内序号，最后定位首个权威字段差异。普通内容适配另列，不参与同输入确定性对照。

字段负例复制本轮证据并改写检查点 9 的 `next_entity_id` 及摘要，要求进程非零退出并报告检查点、
字段和输入位置。必要恢复负例破坏本轮存档来源版本，分别验证已有会话不被替换，及新进程恢复入口
非零退出并给出 `base/configuration_version` 阶段。失败日志和损坏存档留存。

## 证据边界与人工步骤

保留四个旧真实入口及其夹具和历史报告：`run-godot-playground-smoke.ps1`、
`run-godot-playground-observation-smoke.ps1`、`run-godot-playground-switch-smoke.ps1`、
`run-godot-authority-checkpoint.ps1`。本票复用其正式领域和 Godot 能力，新增联合序列；没有迁移四切片
的全部用例，也不证明 #118 的入口退役门槛。

人工在图形窗口按下列顺序检查，并记录构建、有效内容、步骤、结果及截图或视频路径：

1. 打开 `straight-rail-train`。确认状态为暂停。自由移动镜头，选中车头时应保持镜头不动；再点击
   “聚焦”和“跟随”，检查转场和目标标示。点“启动列车”“单步”“推进 N 步”“运行”“暂停”，看车辆
   跟随是否连续，步号、速度、状态及最近操作反馈是否和动作一致。暂停后车辆不应被当作停车。
2. 选中并跟随车厢，从 `observe list` 或 `composite query` 记下该车 ID；在控制台执行
   `composite damage <车厢ID> 1 0 1 100`。确认目标消失后提示明确、镜头不跳位并回到自由观察。
3. 放置矿石或推进一步制造未保存修改，点击“切换到另一配置”后选“取消”：来源、步号和未保存标示
   应保留。再次切换选“保存后继续”：确认新配置默认暂停，之前世界的存档 UUID 可以独立读取。
4. 在单独的新存档上测试失败：先“保存”并记录 UUID，把对应 `user://saves/<UUID>/save.json`
   临时设为只读；再修改世界并选择“保存后继续”，应出现保存失败且原会话保留，随后撤销只读。
   另备份这份新存档，改坏其 `world_source.configuration_version`，在“读取存档”中输入 UUID，
   选择放弃当前更改并确认候选失败阶段、原世界与镜头仍在；检查完立即恢复备份。

无人工观察时报告为待验证；headless 的退出码、物理查询或截图采集不代表人工观感通过。

本入口不实施有界录制、任意重放、隔离 ZIP 包或性能测量。普通读档内容适配由既有领域测试覆盖，
若语义内容有变化，须作为独立对照重新记录，不归入上述相同内容摘要的确定性结论。
