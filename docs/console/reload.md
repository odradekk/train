# `reload`：重载内容

[返回命令索引](README.md)

```text
reload
```

参数：无。不接受文件路径、包名或定义 ID，也不是重载场景的命令。

使用方法：修改当前内容源中的定义或资产后，在 Debug 构建中执行 `reload`，检查内容扫描、诊断及重载汇总日志。它调用正式内容重载入口，重新构建并校验候选目录。

- 体素目录有有效变更并发布后，Catalog Generation 递增；仅聚落变更或没有有效变更时不递增。
- 已进入体素开发场景时，重载会基于候选当前定义校验全部占用实例并准备适配。全部成功后才原子发布目录、Generation 和实例变化；缺必需定义或当前朝向不再被允许时整次拒绝，目录、Generation 和世界保持旧状态。
- 已有体素按定义身份采用当前 Mass、Value、耐久上限和碰撞规则；绝对耐久在新上限升高时保持，降低时夹到新上限。占用、实际朝向和实例身份保留，不重建世界。`voxel collide` 与 Godot 派生碰撞在成功发布后采用新规则；领域查询在发布当下即可读到。
- 纯显示文字、Cube 资产或绑定变化可以更新已有体素的查询与画面，不因此改变 Semantic Revision，也不改变碰撞命中。
- 内置内容错误或候选校验失败时拒绝发布，保留原目录、世界和已发布碰撞。非法 Mod 可以整包排除后继续校验剩余候选，但排除后若运行中实例缺必需定义，整次仍然拒绝。
- 已有重载正在进行时，新请求会被拒绝。
- 非 Debug 构建执行该命令会提示 `reload is only available in debug builds.`。

当前限制：车辆、Composite、存档和跨 Chunk 实例适配不在本命令范围内。需要丢弃当前布局并重建初始开发世界时使用 `voxel reset`。
