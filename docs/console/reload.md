# `reload`：重新加载内容

[返回命令索引](README.md)

```text
reload
```

`reload` 把请求交给宿主的内容重载回调。它没有路径、包名或定义 ID 参数；附带 token 会忽略。发布构建执行时会报告该命令仅在 Debug 构建可用。

内容重载会扫描当前内容源，校验候选定义和资产，并在校验通过后发布新的内容目录。没有有效内容变化时不增加 `Generation`。无效 Mod 可以隔离后继续校验其余候选；内置内容错误或候选校验失败时拒绝发布，保留原目录与已发布状态。被排除的内容是否影响宿主已有状态，由宿主注册的候选校验决定。

基础分发器只调用宿主回调。宿主注册的 participant 决定是否增加额外校验；本页不为未注册的世界、车辆、铁路或编辑器适配做承诺。
