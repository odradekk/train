# `reload`：重载内容

[返回命令索引](README.md)

```text
reload
```

参数：无。不接受文件路径、包名或定义 ID，也不是重载场景的命令。

使用方法：修改当前内容源中的定义或资产后，在 Debug 构建中执行 `reload`，检查内容扫描、诊断及重载汇总日志。它调用正式内容重载入口，重新构建并校验候选目录。

- 体素目录有有效变更并发布后，Catalog Generation 递增；仅聚落变更或没有有效变更时不递增。
- 内置内容错误或候选校验失败时拒绝发布，保留原目录。非法 Mod 可以整包排除后继续校验剩余候选，因此出现诊断并不一定表示整个重载失败；以最终汇总为准。
- 已有重载正在进行时，新请求会被拒绝。
- 非 Debug 构建执行该命令会提示 `reload is only available in debug builds.`。

当前限制：PR #47 中的新添加和重置读取当前目录定义，但已有体素的耐久、朝向约束及显示等状态的完整热重载适配属于后续 #46。不要把 `reload` 成功理解为已有世界已完成原子适配；需要重新生成测试世界时使用 `voxel reset`，它会丢弃当前布局。
