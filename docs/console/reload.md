# `reload`：重新加载内容

[返回命令索引](README.md)

```text
reload
```

`reload` 把请求交给宿主的内容重载回调。它没有路径、包名或定义 ID 参数；附带 token 会忽略。发布构建执行时会报告该命令仅在 Debug 构建可用。

内容重载会扫描当前内容源，校验候选定义、资产、引用和设计属性，并在通过后原子发布完整的 `ContentSnapshot`，其中包含体素、蓝图、市场表和聚居地类型。没有有效内容变化时保留同一个快照对象，不增加 `Generation`，也不发送变更通知。

无效可选包整包隔离后，重新校验其余候选的引用；必需包失效或候选校验失败时拒绝整轮发布，保留原快照。当前重载只发布内容，运行实例的引用校验与状态适配在对应玩法中实现，见[候选内容与运行中引用校验](../design/02-definitions-and-content.md#候选内容与运行中引用校验)。

基础分发器只调用宿主回调；重载结果和失败原因由内容日志报告，命令不另行输出成功消息。当前 App 将回调接到同一个 `ContentReloader`。Debug 构建也可以按 Ctrl+Shift+R 发起同样的重载；发布构建不处理该快捷键。
