# `rail follow`：选择跟随相机的存活车辆

[返回命令索引](README.md) · [场景前提与参数](README.md#使用前提与通用参数) · [结果与错误处理](README.md#结果与错误处理)

```text
rail follow
rail follow vehicle 2
```

无参数时只读当前跟随目标与该车当前显示姿态上的焦点、车体朝向。`vehicle <id>` 把跟随目标改到指定存活车辆；未知身份输出 `Rail follow unknown <id>.`，原选择不变。断开后只要该车仍在会话中就保持选择，不会自动跳到前车或活动车头。目标彻底摧毁后的产品回退不在本命令范围。

相机读取 [`rail query display`](rail-query.md) 同一套显示姿态与前/后接触推出的车体朝向，不跟随跳动的权威步位置，也不用速度方向代替车体朝向。切片 4 正式窗口用侧向四分之三观察构图：焦点沿车体朝向的偏移绑定所选车辆定义（开发车头 −5、车厢 +4），不因断钩后该车变成新编组首车而改号；保证一车头一车厢的车体侧面、车钩和接触关系可见；不是 Phase 7 的完整 Orbit/Zoom。本命令不改变模拟、存档哈希或车辆权威变换。

开发场景关闭控制台后可用 `F` 在当前存活车辆间循环切换，效果与本命令相同。Playground 镜头不读本命令的跟随状态，改用 [`observe follow`](observe-follow.md)。
