# `rail follow`：选择跟随相机的存活车辆

[返回命令索引](README.md) · [场景前提与参数](README.md#使用前提与通用参数) · [结果与错误处理](README.md#结果与错误处理)

```text
rail follow
rail follow vehicle 2
```

无参数时只读当前跟随目标与该车当前显示姿态上的焦点、车体朝向。`vehicle <id>` 把跟随目标改到指定存活车辆；未知身份输出 `Rail follow unknown <id>.`，原选择不变。断开后只要该车仍在会话中就保持选择，不会自动跳到前车或活动车头。目标彻底摧毁后的产品回退不在本命令范围。

相机读取 [`rail query display`](rail-query.md) 同一套显示姿态与前/后接触推出的车体朝向，不跟随跳动的权威步位置，也不用速度方向代替车体朝向。本命令不改变模拟、存档哈希或车辆权威变换。

开发场景关闭控制台后可用 `F` 在当前存活车辆间循环切换，效果与本命令相同。
