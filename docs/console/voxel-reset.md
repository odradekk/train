# `voxel reset`：重置开发世界

[返回命令索引](README.md) · [场景前提与参数](README.md#使用前提与通用参数) · [朝向编码](README.md#朝向编码) · [结果与错误处理](README.md#结果与错误处理)

```text
voxel reset
```

参数：无，不能附加其他参数。立即丢弃当前场景的全部体素修改，按当前切片的正式生成入口和当前目录中的 `core:iron-ore` 重建基底，朝向恢复为 `px_py`，耐久取当前定义最大值。没有撤销或确认步骤。切片 1 重建 512 格；切片 2 重建 1,088 格（地面加 `14..17` 交汇块）。Seed 只保留为身份，不引入随机。已分配的存档 UUID 与显示名保持不变；磁盘上的上一份有效存档也不删除。要恢复保存过的世界，使用 [`voxel load`](voxel-load.md)，不要把 `reset` 当成读档。

结果以 `Voxel world reset.` 开头，随后给出代表格查询和总体素数：切片 1 查询 `(4,4,4)`，切片 2 查询 `(15,16,15)`。若使用原始定义，应显示耐久 100，以及该切片的初始总数。该操作要求当前目录仍包含 `core:iron-ore`。
