# `voxel reset`：重置开发世界

[返回命令索引](README.md) · [场景前提与参数](README.md#使用前提与通用参数) · [朝向编码](README.md#朝向编码) · [结果与错误处理](README.md#结果与错误处理)

```text
voxel reset
```

参数：无，不能附加其他参数。立即丢弃当前场景的全部体素修改，按当前目录中的 `core:iron-ore` 重建初始 512 格，朝向恢复为 `px_py`，耐久取当前定义最大值。没有撤销或确认步骤。

结果以 `Voxel world reset.` 开头，随后给出 `(4,4,4)` 的查询结果和总体素数。若使用原始定义，应显示耐久 100、总数 512。该操作要求当前目录仍包含 `core:iron-ore`。
