# `dev`：开发检查器

[返回命令索引](README.md)

```text
dev
dev open
dev close
```

`dev` 打开独立检查窗口，`close` 隐藏窗口。仅 Debug 构建且 App 已接入新 `HostCoordinator` 时注册；默认旧宿主没有此命令。它不负责创建会话。窗口关闭不会取消正在进行的推进，需要使用窗口中的取消按钮。

## 推进与条件

普通会话支持暂停、单步、推进指定步数，以及运行到目标步、指定领域事件、对象内部故障或匹配命令被拒绝。拒绝条件使用规范命令负载的 `kind`；勾选对象匹配时同时匹配已选对象的稳定身份，不勾选时只匹配 kind。启用前的回执不会触发。事件条件填写已声明的 `CoreEvent` 具体类型名，例如 `TrainArrived`，只观察启用后的新边界事件。对象条件保存稳定身份，目标失效时停止并保留原身份。

条件可设置最大步数。运行开始时暂停普通自动驱动，再按完整边界逐步推进，每帧使用暂定 5 ms 预算；预算不能中断核心单步。条件、步数上限、通知暂停和冻结可在同一边界触发，窗口保留所有停止原因，冻结优先显示。取消不会再推进；换局清除运行条件，检查点与说明标记仍保留在本进程内。

## 对象、命令与检查点

对象页按公开类型及稳定编号查询固定读视图，显示嵌套运行字段。`missing` 表示原对象已经失效；查询或显示不可用会保留身份并说明原因，不替换成其他对象。命令页显示当前录制或重放窗口的范围、缺口、原始规范参数及完整回执，可按 `kind`、受理结果和关联对象筛选。

检查点保存说明、模拟位置、世界种子、运行环境、核心输入身份及模块检查点；说明标记保存文字、位置和运行绑定。二者只存于进程内存，换局保留，退出进程即丢失。比较依次检查位置、世界种子、运行环境和核心输入身份；前三项不同显示不可比，输入不同显示内容适配，均不调用核心比较。元数据一致才委托核心比较，并显示一致或首个字段差异。检查点捕获不写普通存档。

## 只读重放

“打开复现包”选择录制 ZIP，经普通会话的离开保护后后台准备隔离重放。失败或取消保留原会话；只有准备完成且操作身份、原绑定与内容基准仍有效时才替换。载荷分别交给 Core、Content 解码，宿主不从安装目录补齐内容。

有故障片段时优先选择清单中的第一个故障片段。普通窗口选择按模拟位置排序后、能连续无缺口到达录制截止位置的最早起点；没有可用起点时拒绝打开。重放按录制逐步运行，可指定目标 `step:sequence`，显示实际停止位置、首个差异或故障。`sim step` 不用于重放。

重放不能提交新命令、重载当前内容或直接编辑。导出当前完整边界会生成新 UUID 的普通存档，覆盖已有文件需要确认；导出不会把当前重放变成普通会话。必须再通过普通读档打开副本，才能回到普通会话的修改入口。

## 场景与性能

场景页提供区块、线路段、原点、拾取射线和中心线开关，以及重新生成当前场景。它们通过 Scenes 公开契约取得调试线；重新生成不改变核心权威状态。没有接入场景控制器或 Scenes 未提供相应线时，不承诺显示该层。

性能页显示 Godot 进程帧耗时、静态内存、对象数、请求与实际模拟速度及当前调试线数。模拟耗时和录制容量明确标为“未采集”；这些显示不代表已达到阶段性能目标。
