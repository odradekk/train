# `quit`：请求退出

[返回命令索引](README.md)

```text
quit
```

`quit` 把退出请求委托给宿主处理。命令本身不处理存档，也不切换世界；是否有离开保护、如何确认和最终如何退出由宿主决定。语法：无参数，附带 token 会忽略；例如 `quit extra` 仍提交同一个退出请求。

新契约宿主存在时，控制台退出、窗口关闭和菜单退出使用同一离开保护：先等正在进行的文件发布给出结果，有手动未保存更改时选择“保存／不保存／取消”。保存失败或取消留在原对局；核心冻结时只提供“不保存／取消”。自动存档不清除手动未保存标记。默认旧启动路径仍直接退出，真实工厂切换归 #424。
