# `voxel redo`：重做最近一次已撤销编辑

[返回命令索引](README.md) · [结果与错误处理](README.md#结果与错误处理)

```text
voxel redo
```

命令在暂停状态重做面板或控制台最近一次成功撤销的体素编辑。重做同样提交新的正式编辑，分配新编辑编号并重新校验当前世界，不回退模拟步、编号或实体 ID。当前状态不满足原操作时整次拒绝，世界与历史不变。

没有可重做记录返回 `Edit NoHistory.`。模拟正在运行返回 `Edit SimulationRunning.`，暂停后可重试。面板中有未结束草稿返回 `Edit VoxelDraftExists.`，须先提交或丢弃草稿；草稿自身使用面板内的草稿重做。成功提交一项新的可撤销体素编辑会清除重做分支，失败提交不会清除。共享历史、64 项容量、淘汰提示及结束边界见 [`voxel undo`](voxel-undo.md)。
