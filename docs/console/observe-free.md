# `observe free`：回到自由观察

[返回命令索引](README.md) · [Playground](README.md#playground具名固定配置)

```text
observe free
```

参数：无。结束聚焦或跟随，镜头停在当前位置与朝向（包括过渡中途），转为自由观察；选择保留。输出 `Free mode free selection ...`。已是自由观察时同样返回 `Free`。

自由观察不需要世界中有车辆。控制台关闭时：`W`/`S` 前后、`A`/`D` 左右、`E`/`Q` 升降，按住 `Shift` 加速；右键拖动转向，滚轮沿视线推拉。聚焦/跟随中这些平移键不生效。

Playground 画面快捷键 `C`、右侧面板“自由观察”按钮与本命令等价。本命令不暂停、不推进、不修改会话。
