# `observe free`：回到自由观察

[返回命令索引](README.md) · [世界编辑器](README.md#世界编辑器具名固定配置)

```text
observe free
```

参数：无。结束聚焦或跟随，镜头停在当前位置与朝向（包括过渡中途），转为自由观察；选择保留。输出 `Free mode free selection ...`。已是自由观察时同样返回 `Free`。

自由观察不需要世界中有车辆。控制台关闭时：`W`/`S` 前后、`A`/`D` 左右、`E`/`Q` 升降，按住 `Shift` 加速；右键拖动转向（须在画面中按下；松开被控制台、面板或窗口失焦截获时拖动即结束，之后不按右键的移动不会转向），滚轮沿视线推拉。聚焦/跟随中这些平移键不生效。

世界编辑器画面快捷键 `C`、右侧面板“自由观察”按钮与本命令等价。本命令不暂停、不推进、不修改会话。

鼠标观察和快捷键仅在世界视图获得输入时响应。点击世界视图获得输入；点击工具、检查器或文本框后，世界平移和拖动结束，文本输入不移动镜头。控制台打开后同样结束拖动和平移；关闭控制台须重新点击世界视图获得输入。
