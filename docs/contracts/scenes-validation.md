# 体素引擎：失败与验证约定

本页记录失败与验证约定，与[契约目录](scenes.md)一起使用。

## 失败、线程与验证

SceneResult.Success 表示本次操作正常完成，包括仍在加载的帧和含无效设计的编辑状态。Failure 表示预期拒绝，至少一条 SceneProblem；Faulted 表示体素内部故障，宿主报告并停止故障会话的可变调用，不影响核心。缺失内容本身是诊断和占位，不强制变成整个场景故障。正常输入的生成算法失败必须报告，不能偷偷换种子或篡改核心长度。

稳定错误码至少覆盖 `target_missing`、`stale_request`、`stale_hit`、`content_missing`、`build_failed`、`edit_locked`、`invalid_operation`、`region_limit`、`occupancy_conflict`、`outside_envelope`、`scene_internal_fault`。Godot 不解析 Detail 分支；SceneProblem.Content 和 Package 保留引用及已知来源包，内容提供了来源时不得丢弃，确实未知时 Package 为空。宿主据此同时在界面与控制台显示缺失资料，不按设计哈希猜包名。绑定、内容世代或业务输入身份不匹配、Observe 位置倒退及事件顺序或重复错误属于接口前提违反，抛 ArgumentException，接入前仍须检查；真实交互过期继续返回 stale_hit、stale_request。default 集合/非有限数/无效枚举等编程前提错误抛 ArgumentException；关闭后的修改调用抛 ObjectDisposedException，AcceptEvaluation/MarkSaved 则按约定返回 false。

工厂无可变调用会话状态，可独立创建多个候选；世界和编辑会话的变更只在各自协调线程串行执行。只读设计预览的 Present 和 Dispose 在调用方协调线程串行调用。固定帧、输入快照与模板预览可并发只读。体素背景线程不调用 Godot 或内容加载器、不读文件；除可选流式观察器的诊断事件外，不回调宿主。产品使用的内部任务完成状态仍只经 Present 暴露。

[消费样例](../../prototypes/scenes-contract/README.md)证明公开面可调用，不提供生产算法或复制业务规则的替身。后续共享契约用例须对真实实现及有限情景替身分别执行：

| 输入场景 | 输出断言 |
| --- | --- |
| 固定核心/内容与相邻步 | 同帧姿态和拾取一致；不外推，暂停、倒车、编组中心和读档重建一致 |
| 分段未完成、跟随切换、旧任务晚到 | 进度与雾明确，旧请求不能接入，删除对象不复活，不等待核心 |
| Base 不符、准备重试、浮动原点平移 | 不部分接入资源；准备期间姿态、相机和拾取使用 P，完整替换可恢复；平移及效果不重复 |
| 保留旧网格/帧后更新或关闭 | 旧值不变，无显式归还义务；新交互拒绝旧绑定 |
| 缺失单格/未知范围复合体 | 前者原格占位，后者放置点标记且不拦截 DDA；诊断可定位 |
| 编辑区域、嵌套副本与封闭引用 | 原子提交、门槛确认、拒绝无写入、锁不能绕过、导出副本可交给内容 |
| 新编辑后校验/保存迟到、撤销、关闭 | 不启用旧结果，不清除新修改；显式保存版本与整局落盘分离 |
| 模板缺失或重复地块编号 | 已知部分可预览，按数组下标定位，预览不承担发布校验 |

实际隔离仅提供目标契约/样例和允许的 Core、Content 契约，不提供产品实现源码或程序集。真正模块独立测试按[验证规范](testing.md)另行实现；真实 Godot 的资源、绕序、Custom Mesh 轴向、相机、闪烁与碎片时间，以及视觉观感均须在那里验证，不能用纯数据测试替代。

区块边长、分段长度、预取距离、单帧重建预算、内存峰值和 GC 成本不在此冻结。实施时测量首次进入、长编组跨分段/原点、局部破坏和大尺寸编辑；按已有 Demo 负载验证后决定预算。若普通不可变数据不能满足实测要求，再按受控变更流程修订，不预建缓冲池公共协议。

## 本票验证记录

2026-10-10，使用仓库锁定的 .NET SDK 10.0.112，在新临时目录仅复制 global.json、Core/Content/Scenes 三个契约项目和三个消费样例的源码，排除 bin/obj；六条项目引用全部指向允许的契约，没有产品实现源码或预编译程序集。三个样例构建均为零警告、零错误；最后的诊断及校验来源修正后，体素样例再次在该隔离目录构建通过。

内容 Schema 检查通过 57 份样例；14 份新增或修改 Markdown 的 247 个相对本地链接（其中 125 个带锚点）检查通过，空白检查通过。只读接口审查处理了嵌套副本导出、草稿保存完成、诊断来源及评估来源责任。没有运行真实 Scenes 行为、Godot、目标硬件性能或游戏联调验证；这些仍是后续实施与原型的工作。
