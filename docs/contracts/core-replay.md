# 核心模拟层：严格重放约定

本页记录严格重放约定，与[契约目录](core.md)一起使用。

## 严格重放

宿主读取复现容器并还原包内内容投影，调用 `PrepareReplay`；核心比较原构建、模拟版本、兼容环境、配置和输入身份。依赖不完整、格式无法理解或身份不符明确失败，不跳过命令，也不读取安装目录补救。

当前 `CoreReplayInput.FormatVersion` 为 2（旧版 1 因检查点与命令回执包含旧地块档位而拒绝），与命令输入格式 2 分开。#385、#546、#332、#342、#541、#343、#350、#344、#352 保持重放格式 2 和命令格式 2；重制起点为核心状态格式 23，检查点按新的世界结构重制。旧起点载荷由状态格式校验拒绝；检查点规范文本不带状态格式号，旧结构由世界载荷校验拒绝。不因这些内部变化再升重放外壳格式。`RuntimeIdentity` 的 `GameBuild`、`SimulationVersion`、`OperatingSystem`、`Architecture` 和 `DotNetRuntime` 全部按 Ordinal 匹配；不匹配返回 `incompatible_replay`，字段为 `OriginalRuntime.<成员>`，兼容粒度由宿主提供的字符串决定。准备阶段解码起点与全部命令，核验记录位置、检查点格式／SHA-256，并从 `contentHistory` 取得起点及所有命令前后、目标输入身份的投影；任一依赖缺失返回 `content_missing`。不支持的版本和种类返回 `unsupported_format`，非法字段和位置返回 `invalid_state`，附字段路径；带故障的起点不能作为可执行起点。准备阶段也对全部 `contentHistory` 使用与 `PublishContent`、普通恢复相同的内容投影校验，非法投影抛 `ArgumentException`，不能在执行一段前缀后才发现输入无法使用。检查点复用世界载荷读取与校验，世界内部差异以 JSON Pointer 报告。世界来源含生成配置，未来新增领域字段仍须同步接入。

重放只有读取、推进和边界捕获入口，没有 Submit。`Advance` 到达预算、指定位置、记录截止位置、首个差异或故障即返回明确停止原因；`stopAt` 可以指定同一步内某条命令后的边界，不能越过它。同一步内的命令按记录位置顺序执行，拒绝结果也核对。`CompareCheckpoints` 返回首个字段差异，不要求宿主解析检查点文本。`CaptureBoundary` 可作为普通读档候选建立可编辑副本；此后当前内容适配属于新会话，不改原重放或声称其仍是严格复现。

步骤预算计实际推进的模拟步数；当前边界上的命令不消耗预算，因此 `Advance(0)` 可以执行同一步命令，`stopAt` 仍先于下一条命令检查。指定已过去或记录范围内不存在的边界是编程错误，抛 `ArgumentOutOfRangeException`；指定记录末尾之后的位置仍在记录末尾停止。回执按完整决策和嵌套集合内容比较，不用 record 的引用相等判定。检查点按稳定字段顺序比较并报告 JSON Pointer、预期及实际值，伪造摘要或非法文本返回失败；位置相同的健康与故障边界分别核对。终止后重复推进保持终止位置，不重复返回事件；未重现记录中的故障时，不能暴露超出录制末尾的状态。
