同步最新 GitHub 状态

在仓库根目录运行以下命令，然后重新打开或刷新本页。需要 Python 3 和已登录的 GitHub CLI；脚本只读取 GitHub 并更新此 HTML 内嵌的数据。

python -X utf8 docs/roadmap/refresh-roadmap.py

单个 HTML 可直接双击打开，也可复制分享。浏览器不保存 GitHub 凭据，不自动联网刷新。
