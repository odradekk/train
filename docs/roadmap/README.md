# 完整 Demo 路线图

用浏览器打开 [demo-roadmap.html](demo-roadmap.html)。单个 HTML 包含数据、样式和交互，可离线打开或复制分享，无需安装前端依赖。

- 上方查看共享准备、六个阶段和验收关卡。
- 点击阶段展开依赖图；箭头从前置指向后续，点击节点高亮直接依赖并查看工单详情。
- “全部任务”提供完整清单，可按标题、编号、职责与状态筛选。详情内可跳转 GitHub。
- 依赖图支持缩放和滚动；“适应宽度”用于观察整体结构，放大后查看节点文字。

## 更新状态

在仓库根目录运行，然后刷新浏览器：

```powershell
python -X utf8 docs/roadmap/refresh-roadmap.py
```

需要 Python 3 和已登录的 `gh`。脚本只读获取 `odradekk/train` 的 Demo 父票、原生子票和依赖闭包，替换 HTML 内嵌数据，不修改 GitHub。获取失败时保留原有页面。页面右上角标明快照时间；浏览器本身不会自动同步。

## 如何读状态

进度只统计 Demo 父票之下的实施任务和六张验收票；外部已完成的规划票作为前置背景保留，不计入 Demo 完成率。首次生成时为 96 张任务、6 张验收票、285 条原生依赖。

“无阻塞”指快照内的原生前置已关闭，不代替实施 SOP 中的开工与交付流程；“已分派”只表示有负责人，不能据此判断正在开发。取消的票不计入已完成。阶段放行仍以验收票记录的真实联调、人工检查和用户确认为准，页面不会依据子票完成率自动判定验收通过。

阶段内按依赖层排列，不代表固定工期或人员安排。共同前置和跨阶段依赖汇总在图上方，逐票完整依赖列在详情中。职责来自工单正文的“责任”字段，组合责任按主要角色分组；阶段名称和短说明是本轮六阶段计划的导航，重组阶段时需同步页面。

权威任务范围、依赖和验收记录见 [Demo 父票](https://github.com/odradekk/train/issues/297)及其子票；本页用于浏览和追踪。
