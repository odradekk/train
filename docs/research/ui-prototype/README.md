# 列车经营 UI 原型

用浏览器打开 `index.html`，按 1920×1080 查看效果最好。左下角紫色「原型」按钮不属于游戏界面：可以重置、触发通知、把资金调低，或直接跳到某个界面。地址栏加 `#场景名` 也能直达，例如 `index.html#plan-new`。`shoot.sh` 用无头 Edge 批量截图到 `shots/`。

`inventory/` 是重设计前对现有 UI 的盘点（2026-10-31，基于 master a24abd2a）。

## 已定方向（用户 2026-10-31）

- 布局：停靠式侧栏。左侧导航和列表，右侧检查器，复杂编辑在居中工作区，一次只开一个。
- 地图单击只选中并打开检查器；双击或检查器里的「进入场景」才进 3D 场景。
- 推进顺序：先做骨架和主路径，确认后补全全部界面。
- 范围包括创作面板、控制台和开发检查器。

## 第 1 轮（2026-10-31）

范围：顶栏、左侧导航与列表、宏观地图、四类检查器（聚居地、列车、线路、空节点）、通知、主路径「买车 → 编组 → 写计划 → 发车」。

### 界面约定

| 区域 | 约定 |
|---|---|
| 顶栏 44 px | 左：暂停、倍速、时间、自动暂停原因；中：场景里的面包屑和返回；右：资金（变化时短暂显示增减）、通知、菜单 |
| 左侧导航 64 px | 车队、线路、聚居地、报告、设计、战斗；图标加文字，带待处理数；再点一次收起 |
| 左侧列表 340 px | 搜索、筛选、分组；点行选中对象，不移动地图视角（设计文档 08 的规则），按 F 或点检查器的定位按钮才移动 |
| 右侧检查器 440 px | 选中对象的全部信息和操作；标题、状态、定位、进入场景、关闭；标签页；底部固定主操作 |
| 工作区 | 编组、运行计划等多步编辑；居中，遮罩不响应点击，防止误关丢失编辑 |
| 提示条 | 底部居中，最多 3 条，6 秒消失（严重级不消失）；点击选中相关对象，不切场景 |

- Esc 依次关闭：对话框、弹出菜单、工作区、检查器、列表、场景；都关着时打开菜单。
- 快捷键：空格暂停/继续，1–4 切倍速，T/L/J/R/D/B 打开六个列表，F 定位，V 进入场景，WASD 平移地图，Ctrl+S 保存。
- 确认：花钱买车、宣战、解编这类不能撤销的操作先确认，问题里写明后果和金额；交易按钮本身写明数量和金额，成交后就地显示结果。
- 置灰按钮旁边写原因（如「资金不足，还差 1,200」「先停车才能解编」）。
- 报价随输入实时更新，没有「获取报价」按钮。

### 主路径步数

| 任务 | 现状 | 原型 |
|---|---|---|
| 买 3 辆现车、编组、写一条往返计划、发车 | 约 27 次点击，跨 4 个面板 | 约 15 次点击，一条连续流程 |
| 在市场买 10 件货 | 9 次 | 3 次（选聚居地、市场、点货物行后点买入） |
| 查看地图上一列车的状态 | 打开车队列表再点行 | 1 次（点地图上的列车） |

### 验收

用户 2026-10-31 验收通过。原先待定的四处按原型现状定下：宏观地图用偏暗的灰绿底色；节点小地图放左下角（与设计文档 08 的右上角不同，因为右侧给了检查器）；提示条放底部居中；列表快捷键用 T/L/J/R/D/B。

## 第 2 轮（2026-10-31）

范围：自有聚居地（概况、库存与装卸、建筑与生产、工地）、建造建筑、委托制造、停放车辆的修理/出售/拆解、租用仓库（新租、续租、仓库与列车装卸）、列车在聚居地修理和调整编组、解编、建立聚居地、战斗、交战规则、敌对聚居地与占领、经营报告。

### 界面约定

- 聚居地检查器按关系分页：自有是「概况、库存、建筑、车辆」，非敌对是「概况、市场、车辆、仓库」，敌对只有概况。现状的 8 个标签（库存、人口、地块与建筑、市场、现车、仓库租用、生产、建造与工地）合并进这几页：人口进概况，生产并进建筑，现车和委托并进车辆。
- 生产在建筑行里设置：点建筑展开「生产流程、启用、优先级」，改动立即生效，没有「应用计划」按钮。停工原因写在建筑行里，并给出处理办法。
- 委托制造和建造建筑共用一个工作区：左边选蓝图或建筑，右边是材料表（每种材料来自哪里、当地买多少、多少钱）、货物来源顺序、合计和工期。报价随选择实时更新，按钮写明金额。材料不够时说明缺多少、怎么补。
- 修理不单独开工作区：选中车辆后按钮直接写金额，材料在当地购买。
- 装卸和买卖用同一种展开行：非敌对聚居地有租用仓库时，市场行多出「从仓库装车、卸到仓库」；自有聚居地的库存行是「装上列车、卸到库存」。
- 建城条件写成检查清单：列车是否到站、每种起始材料差多少、去哪里买。
- 战斗：地图上有闪烁的战斗标记，点开是战斗检查器。我方每列车一个「撤退」按钮，敌方每个目标点一下就集中攻击，战报写成完整句子。
- 交战规则在列车的「交战」页，最上面用一句话复述当前规则，改动立即生效。
- 经营报告用左侧导航的「报告」直接打开居中工作区（不是列表），分「列车、聚居地、收支明细」三页；列车行展开是运行报告明细和未完成规则的原因，可以直接跳去改计划。
- 不能撤销且有后果的操作先确认：宣战、占领、拆除建筑、出售和拆解车辆、解编、建城。委托和建造在工作区里已经列出全部费用，按钮写明金额，不再弹确认。

### 新的假设

- 现在没有取消委托的命令，原型照现状不提供取消，只在工作区底部提示「委托后不能取消」。
- 快速修理的材料全部在当地购买，不动列车上的货。要用自己的货物，走委托工作区。

### 验收

用户 2026-10-31 让开始第 3 轮，第 2 轮的做法和两条假设照原型保留。

## 第 3 轮（2026-10-31）

范围：主菜单、新游戏、存档与读档、设置、报告问题、蓝图库、新建设计、设计编辑器、改装（从列车进入编辑器，完成后委托改装）。

### 界面约定

- 主菜单：最上面是「继续游戏」，写明最近存档的名称、游戏时间和保存时间，启动后焦点就在它上面。下面依次是新游戏、读取存档、设置、退出游戏。内容加载时显示进度，并说明加载完才能开始。现状里「存档」排在「退出」后面、初始焦点在「退出」，这两点都改掉了。「从示例存档开始」只在开发构建出现。
- 新游戏：生成配置配一句说明；种子旁有「随机」按钮，默认不再是 0；可以填存档名称。内容包缺失时直接写明缺哪个、后果是什么。生成世界时显示进度，可以取消。新对局开始时是暂停的。
- 存档与读档：主菜单和游戏菜单进的是同一个界面。存档按世界分组，右边显示详情（游戏时间、保存时间、资金、列车、聚居地、内容包）。双击直接读取。游戏中最上面一行是「保存当前对局」。读档或返回主菜单时，如果有未保存的进度，问「保存后读取 / 不保存，直接读取 / 取消」。不再显示存档的 GUID。
- 游戏菜单：保存（Ctrl S）、存档与读档、设置、报告问题、返回主菜单、退出游戏。「返回主菜单」不再藏在存档窗口里。
- 设置：左侧分「显示、游戏、通知、按键、关于」，改动立即生效。切换窗口模式后问是否保留，10 秒内不确认就恢复。通知设置从 16 个下拉框改成一张表，每类通知点选「只显示 / 降到 1× / 暂停」。按键页列出全部快捷键，可以改键；新按键与已有按键冲突时两者互换，并给出提示。
- 报告问题：先用一句话说明复现包是什么、里面有什么。记录状态用普通话描述，比如「读档后记录重新开始」，不再出现「缺口」「起点」这类词。导出后显示文件路径，并提供「打开所在文件夹」。
- 蓝图库：左侧导航「设计」直接打开居中工作区。左边按库分组（本局蓝图库、用户内容库、内容包、草稿），每个库有一句说明；中间是带缩略图的卡片；右边是详情和按库给出的操作。内容包里的蓝图只读，主按钮是「复制到本局蓝图库并编辑」。草稿用普通的话描述，不再显示 C# 记录文本。
- 新建设计：名称、类型；车辆选尺寸档位，并显示外形上限；建筑选地块和设施，设施是勾选项，不再手输英文标签；最后选保存位置。
- 设计编辑器：
  - 工具（选择、单格、笔刷、长方体）放在左侧竖条，动作（添加、移除、涂装、替换）放在上方选项栏。两者都有快捷键：V/B/N/M 切工具，1–4 切动作。按住 Shift 临时移除，按住 Alt 点击吸取体素和颜色。
  - 点一下立即生效，没有「应用预览」。悬停时显示半透明预览：绿色表示可以放，红色表示不能放，左下角写明原因（例如「超出中型的外形范围」）。长方体是点两下：先点一个角，再点对角。
  - 选择工具：点设备选中整件设备，点车体选中单格，按住 Shift 多选。选中的东西外面有虚线框，被挡住也看得见。选项栏换成移动、旋转、复制、涂装、删除，方向键和 PgUp/PgDn 也能移动。移动受阻时说明原因。
  - 右侧分「体素、设备、结构、数值」四页。所有下拉框都有标签；车体按体素种类汇总，不再每格一行。底部常驻一条摘要：质量、载量、价值和问题数，点一下跳到「数值」页。问题旁边直接给修复按钮，比如「放置转向架」。
  - 顶栏：退出、名称（点击改名）、撤销/重做、「世界已暂停」、是否已保存、保存草稿、保存蓝图。保存蓝图时，有问题的设计不能保存，但仍可以存草稿；同名时提示会覆盖。保存后留在编辑器里，不再关闭编辑器跳去蓝图库。
  - Esc 依次取消长方体、结束设备放置、清空选择，最后才退出；退出时有未保存的修改会先问。
- 改装：列车停在有服务的聚居地时，「车辆」页每辆车后面有「改装…」。编辑器进入改装模式，底部摘要显示和原车的差别。点「完成改装方案」后打开委托改装工作区，列出新增材料、费用和工期，委托后列车在改装期间不能运行。

### 新的假设

- 编辑器的大批量操作（设计文档 15 规定超过 512 格先确认）原型改为不确认、靠撤销恢复，因为撤销不限步数。
- 节点场景的 3D 视口仍是占位画面；编辑器视口是简化的等轴视图，只用来演示操作方式，真正的编辑器仍是 3D 相机。

### 验收

用户 2026-10-31 让开始第 4 轮，第 3 轮的做法和两条假设照原型保留。

## 第 4 轮（2026-10-31）

范围：控制台、开发检查器、创作面板。细节盘点见 `inventory/05-dev-tools.md`。

### 界面约定

- 控制台和开发检查器合并成一个**开发工具底栏**，贴在游戏画面底部。按 ` 开关，开发构建的游戏菜单里也有入口。上沿可以拖动调整高度。打开时，检查器、列表、地图控件和提示条都往上让出位置，不会被挡住。玩家构建里底栏只有「控制台」一页。
- 控制台：
  - 输入时弹出补全建议，命令和参数都有一句说明。Tab 补全，↑↓ 选建议或翻历史。输入框上方常驻当前命令的用法。
  - 输出按「全部、警告和错误、信息、调试」筛选。每行写明时间、级别（颜色加文字）、分类，可以选中复制；另有「复制全部」和「清空」。
  - `help <命令>` 显示一条命令的用法。打错命令时会提示最接近的命令。所有提示统一用中文，并说明怎么改，比如「先输入 sim pause 暂停」。
  - train 命令出错只在控制台里提示，不再弹出游戏的「操作未完成」面板。
- 推进与重放：继续/暂停、单步、推进 N 步。「运行到条件」的参数会随条件种类变成合适的控件：事件类型用下拉，对象取当前选中对象。运行中显示已推进的步数，可以取消。打开复现包会在隔离的会话里重放。
- 对象：默认跟随地图上选中的对象，显示它的内部数据（带语法颜色），可以定位和复制 JSON。关掉跟随后，可以按类型和编号查找。
- 命令记录：按命令种类、结果、是否与选中对象有关来筛选。表格列出序号、步、命令、结果、来源、对象和参数；点对象会选中它；被拒绝或出故障的命令展开后显示原因。顶部写明记录覆盖的步数范围。
- 检查点：给检查点起名后捕获，勾选两个进行比较，先勾的是「基准」，后勾的是「对照」。比较结果写成一句话。标记可以给某一步写注记。
- 场景与性能：调试线开关改用中文名称（区块边界、铁路分段等）。性能指标显示成 ms、GiB 这类单位；倍速跟不上时直接说明。
- 创作模式：从主菜单或游戏菜单（开发构建）进入，是和设计编辑器一样的全屏模式，进入时世界暂停。
  - 左边是定义树：按种类分组、可以搜索，有问题、未保存、待写入的定义各有标记。
  - 中间是表单：按「基本、模拟、行为、朝向与碰撞、表现」分节。枚举用下拉框，选项是中文名；引用字段改成选择框，只能从同类定义里选；数字带单位；可以留空的数字提示「使用默认值」；资产路径旁有「选择文件…」。字段一改就校验，错误写在字段下方。
  - 右边是预览，改动后自动更新，不再有「更新预览」按钮。
  - 聚居地模板的地块可以在俯视布局图上拖动，按 R 旋转。选中的地块和表单里的那一行相互高亮。重叠的地块标红，并写明和哪一块重叠。
  - 只读的定义种类（工序、规则等）直接说明要去改源文件。
  - 新建定义时，本地 ID 实时检查格式和是否重复。
  - 写入：先保存草稿，再「写入包并重载」。确认框列出要写的定义，并提醒不要同时用别的工具改包。写入时按步骤显示进度。失败时用一句话说明后果（一个文件都没写、内容保持原样、草稿还在），每条诊断带「定位」，点了会跳到对应的定义。

### 新的假设

- 开发工具底栏只在游戏画面里出现；主菜单、设计编辑器和创作模式里不能打开控制台。
- 创作面板改成全屏模式后，不再能一边看着游戏一边改定义。现状也是打开表单就进入编辑暂停，所以没有失去能力。
