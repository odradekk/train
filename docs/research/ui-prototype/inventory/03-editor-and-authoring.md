**结论**：设计编辑器能完成任务，但链路长。单击只生成预览，要到右栏再点“应用预览”才提交。长方体终点只能键入坐标。大多数下拉框没有标签。技术标识和 C# 记录文本直接显示给玩家。下文“确认”来自代码，“推测”未运行验证。

## 2 逐个视图

### 2.1 设计编辑器

**控件（界面原文）**
- 顶栏：输入框“名称”“说明”；按钮“更新名称说明”“撤销”“重做”“保存草稿”“保存蓝图…”“退出”“返回车辆服务”。后者仅车辆实例显示（:306）。
- 左栏：体素、形状、朝向三个下拉，均无标签。体素项文字为“名称 · Value n · x t”。接着是颜色按钮和 6 个色卡。工具下拉为“单格／笔刷（拖动松开一笔）／长方体／选区”。动作下拉为“添加／移除／替换／涂装／形状”。然后是“笔刷宽度”、轴下拉“工作平面 X/Y/Z”、“平面坐标”、“使用拾取表面平面”、“启用高度剖切”、“最高可见 Y”、“重试场景”。最后是“大型设备蓝图库”，每个设备两个按钮：“放置 库 · 名称”“替换为 名称”。
- 右栏：多选元素列表，行文如“↳ 父ID / ID · 体素 (x, y, z) [锁定]”。按钮“进入所选设备”“返回上层”“将所选设备另存为蓝图…”。6 个数值框：“X／移动量 X”到“区域终点 Z”。按钮“设计规格…”“预览精确参数”“应用预览”“框选区域”“移动选区”“复制选区”“选区旋转 90°”“删除选区”“选区涂装”“选区形状”。
- 底栏：状态行、预览行、评估文字、诊断行（带“定位”按钮）。

**视口操作**（WorldSceneView.cs:134-157；DesignEditorPanel.cs:254-298）
- 左键点击：拾取并把格坐标写入 X/Y/Z，生成预览。添加时取命中面的相邻格，未命中则落在工作平面。不提交。
- 笔刷：左键拖动取样，松开后预览并立即提交，超过 512 格才确认。
- 选区工具：点击选中单个元素，多选只能在右栏列表里做。
- 右键拖动环绕，滚轮缩放。
- 快捷键只有四个（project.godot:44-65）：Ctrl+Z、Ctrl+Y、Ctrl+S（保存草稿）、Esc（退出）。没有切换工具、旋转、删除、应用的快捷键。

**步骤数**
- 新建车厢并保存：“新建设计…”，填名称、类型、尺寸、位置，点“创建”，选体素和朝向，每格点击加“应用预览”（笔刷一笔一次），“保存蓝图…”，选目标，“保存并退出”。固定开销约 7 次点击，N 个单格约 2N 次，鼠标要在视口和右栏间往返。
- 蓝图放进世界：蓝图库只有“打开／覆盖”“复制”“删除”，没有“建造”入口（BlueprintLibraryPanel.cs:41-54）。入口在其他面板，未读。
- 改装车辆：世界面板“改装车辆…”，编辑，保存草稿，“返回车辆服务”，在服务页“立即应用”。编辑器内没有提交按钮。建筑实例没有返回按钮（:306）。
- 修改并发布一个定义：见 2.3。

**状态反馈**
- 无选中：状态行显示“已选 0”。选区按钮不会禁用（:139-145），点后才报错。
- 校验失败：底栏诊断文字加“定位”。保存蓝图时设计不合法才会拒绝。
- 保存草稿：底栏显示“草稿已保存。”或“本局草稿已保存；保存游戏后写入存档。”。
- 保存蓝图成功：编辑器关闭并打开蓝图库，“蓝图已保存。”随即被 `ClearFeedback` 清掉（EditorService.cs:475-478；BlueprintLibraryPanel.cs:25）。除列表变化外无成功提示（推测）。
- 保存蓝图失败：编辑器先关闭再重新打开草稿（EditorService.cs:411-415, 501-512）。会话重建，撤销历史应丢失（推测）。
- 错误样式：错误只出现在底栏，样式与普通信息相同。面板不读 `HasError`，GameUi.cs:376 只在编辑器关闭时弹窗。
- 未保存：底栏文字“未保存修改”，退出时弹出三选一对话框。
- 撤销重做：按钮随历史禁用，无步数显示。

**可用性问题**
1. 单击只预览，要点右栏“应用预览”（:268-269, 138）。没有预览或不可应用时静默无反应（:246）。笔刷却自动提交（:292-294），两种工具行为不一致。
2. 长方体只能点出起点，终点要在右栏键入三个数（:208, 226）。
3. 体素、形状、朝向、工具、动作、轴、颜色控件都没有标签（:83-85, 98-101）。
4. 同一组数值框兼作坐标、移动量、复制偏移、旋转支点（:134, 140-142）。点击视口会把格坐标写进去，之后“移动选区”把它当位移用。工作平面轴下拉同时是旋转轴，旋转只有 +90°。
5. 改名要“更新名称说明”再“应用预览”两步。每次版本变化还会覆盖输入框（:66-71, 329）。
6. 内部标识外露：“Value”（:394, 441，术语表为“基本货币价值”）。“层级 {ulong}”（:311）。列表和部件行显示数字 ID（:362, 491）。“设备路径 [0,1]”（:518）。“frozen：核心已冻结…”（EditorService.cs:403）。设施标签要手输英文枚举名（Properties.cs:30-31）。
7. 每个体素一行，无类型和颜色（:362），大设计里无法查找。
8. 底栏 220px 塞入六段状态、BOM、部件长串、包络坐标和转动范围，没有图示（:309-317, 481-495）。
9. 重复入口：“保存草稿”与 Ctrl+S，“使用拾取表面平面”与手选轴加坐标，“预览精确参数”与点击预览。
10. 没有悬停预览。高亮只有一种青色，冲突格在 3D 里无标记，只在文字里列坐标（EditorOverlay.cs:22, 77-83；:235-236）。
11. 工作平面网格固定 ±16、单色、无坐标刻度（EditorOverlay.cs:60-66）。
12. 相机：中键平移在编辑器无效（WorldCamera.cs:168，编辑帧无 `NodePanBounds`，推测）。俯仰限制 0.15–1.35 弧度，不能仰视（:16-17）。没有“重置视角”按钮。
13. Esc 直接退出。输入框聚焦时 Ctrl+Z 可能被 LineEdit 先处理（推测）。按钮没有快捷键提示。
14. 三个 AcceptDialog（设计规格、保存有效蓝图、新建设计）只有一个确认按钮，没有取消按钮。保存蓝图对话框取消后不释放（:530-541）。
15. 游戏顶栏在编辑时未隐藏（GameUi.cs:300-315 没处理），推测与编辑器顶栏重叠。
16. “将所选设备另存为蓝图…”会先关闭当前编辑，目标固定为用户库（:127-133）。

### 2.2 蓝图库与新建

- 三段标题：“内容包（只读）／用户内容库／本局蓝图库”，顺序来自枚举 `Packages, User, Local`。每行是名称加“打开／覆盖”“删除…”“复制到本局…”“复制到用户库…”，内容包行只有复制。“已保存草稿”段每项一个按钮。
- 新建对话框含名称、类型、尺寸、地块、建筑类型、设施标签文本框、保存位置。选“车辆”时地块、建筑类型、设施标签隐藏，选“建筑”时尺寸隐藏（:76）。
- 问题：
  - 草稿按钮文字是 `名称 · {draft.Target}`，即 C# 记录的 ToString，如“LocalBlueprint { Id = … }”（:61）。
  - 行里只有名称，没有类型、尺寸、价值，同名无法区分（:38）。
  - 同一个库有多种叫法：本局蓝图库／本局库／本局草稿，用户内容库／用户库／用户草稿（:35, 49, 75；EconomyPanels.Services.cs:377）。
  - “复制到…”实际是打开编辑器，预置为未保存的新稿（:52-53）。
  - “打开／覆盖”一个按钮含两层意思。
  - 新建时选一次保存位置，保存蓝图时又选一次。

### 2.3 创作面板

- 所有控件在同一条 480×650 滚动列里，顺序如下：
  1. “打开开发源码 core 包”。
  2. “Mod 包 ID”输入框。
  3. “选择本地 Mod 目录”。
  4. “重新载入当前源包”。
  5. “定义”列表，每项为“Kind: LocalId”加“网格编辑”“编辑表单”“删除定义…”。
  6. “已保存包草稿”。
  7. “新定义本地 ID”输入框、类型下拉、“新建定义”。
  8. 定义表单。
  9. “保存草稿”。
  10. 资产相对路径输入框、“选择并加入资产”。
  11. 单写入者提示、“写入包并普通重载”、结果文字。
- 表单字段全是文本框。枚举写成“None/FourWay/All24”“None/FullBox/LocalBox”“voxel/blueprint”这类提示（Voxel.cs:60-61, 65；Settlements.cs:54, 76-77）。格式错误只在点保存或预览后，以“{标题}：{值} 格式无效。”出现在列最底（Form.cs:75-80；AuthoringPanel.cs:169-173）。
- 修改并发布一个定义，至少 7 步：“创作…”，打开 core 包，在平铺列表里找定义（无搜索），“编辑表单”，改字段，滚到底“保存草稿”，滚到底“写入包并普通重载”，读底部结果。
- 问题：
  1. “网格编辑”对非蓝图定义也显示，实际打开表单（AuthoringService.cs:121）。蓝图表单另有“编辑体素网格”，入口重复（Form.cs:116）。
  2. 模板地块的位置和朝向要键入坐标和“PxPy”（Settlements.cs:42-45）。3D 预览只读，点地块只是让对应行取得焦点（AuthoringPanel.cs:98）。滚动容器未开跟随焦点，焦点行无样式，推测看不到跳转。
  3. 引用字段手填 ID，没有选择器（如“场景模型蓝图 ID（可空）”“生物定义 ID”）。
  4. 空 ID 可新建，到保存才报错（AuthoringPanel.cs:168）。
  5. 写入结果以“已完成／失败／未执行”文件路径列表呈现（:137-139）。

## 3 与设计文档 15 的差距

| 设计 | 现状 |
|---|---|
| 鼠标与精确参数共用预览 | 只在点击后预览，无悬停，且需另点应用 |
| 工作平面显示轴向、网格、吸附点、坐标 | 只有网格线 |
| 长方体区域工具 | 终点只能键入 |
| 信息面板含最高速度、加速度、载量 | 只显示质量、耐久、Value、BOM、部件能力（`DesignProjection` 无合计速度、加速度、载量） |
| 保存失败草稿不变 | 会话重建，撤销历史应丢失（推测） |
| 创作模式：地块尺寸与朝向在场景模型上放置 | 只有键入坐标，3D 只读 |
| 创作模式：错误定位到具体字段 | 只给格式错误的字段名，内容校验错误混在底部文字里 |
| 快捷键与布局为开放问题 | 只有四个快捷键，界面没有提示 |
