## 1. 游戏与核心循环
- 【文档 00】这是一款自动经营（放置）游戏。玩家当列车长，不操控单个单位，靠计划、规则、建设和战前安排影响世界，可以开着游戏做别的事。没有离线收益。
- 【文档 00】经济、建设、战斗三个循环并列，每个都是"制定计划、观看自动运行、按结果调整"。
  - 经济：运行计划加交易规则，再读运行报告和经营报告，做策略迭代。
  - 建设：聚居地建筑、铁轨、设计列车。
  - 战斗：武装编组加交战规则，战中少量指令，战后修复。
- 【文档 00】Demo 是开放沙盒，没有任务和成就。新局默认暂停并显示宏观地图。

Demo 六阶段里玩家实际做的事（00 的阶段表，加 #305 试玩清单）：
1. 基础贯通：看地图，进节点和线路场景，跟随列车，存档读档，导出复现包。
2. 经济运输：新局（种子 40）后设计划和规则，发车，读经营报告再调整；用市场、库存、租仓库。
3. 设计与委托：复制蓝图，在设计编辑器里编辑并发布，到 NPC 聚居地委托制造、改装、修理，新车编组运行。
4. 自有聚居地：建城，建筑和生产，铁路扩建和修复，看地图的资源与站台层。
5. 战斗与恢复：武装编组，宣战，撤退，投降后占领，清剿，修理后恢复经营，看世界生物层。
6. 完整验收：上述路径连续走通，加保存读档、分支存档、泰坦等大设计编辑（5000 格区域编辑、50 步撤销重做）。

## 3. 窗口、输入、语言、可访问性
- 窗口【文档 08】：支持窗口化、无边框全屏、独占全屏。关闭窗口即退出，有未保存进度会提示。失焦照常模拟渲染，最小化只停渲染。"失焦自动暂停"默认关，帧率上限可配。
- 分辨率：体验目标和美术 07 的像素值都按 1920×1080【文档 00、美术 07】。08 只写世界相机的 Far 按默认 16:9 算，不限制宽高比。最小分辨率和 DPI 未规定。
- 鼠标【文档】：点击、拖动、悬停、平移、缩放、环绕，另有调试用右键菜单。
- 键盘：文档只提"返回键"。快捷键写明"随界面原型确定"（15、08 开放问题），属未规定。
- 实现（非文档）：`project.godot` 有 Ctrl+Z/Y/S、Esc、Ctrl+Shift+R。试玩说明是右键环绕、中键平移、滚轮缩放、Esc 返回。
- 手柄、触屏：未规定，全文没有出现。
- 语言：未规定界面语言和本地化机制。【推断】界面是中文：字体是打包的 Noto Sans SC（美术 07），议题把英文枚举名、内部码、英文报错都当缺陷（#571、#723、#734）。
- 可访问性：只有美术 07 不变量 3（状态不只靠颜色，要有形状、描边或符号，照顾色弱）和"镜头抖动"开关。字号、对比度、键位重绑未规定。设置里的"界面缩放 0.75–2×"是代码已有，文档没写。

## 4. 已有 UI 规则
- 面板【文档 08、CONTEXT】：都在游戏窗口内，可同时开多个，盖在地图或场景上，没有系统窗口。选中对象被摧毁时显示"已不存在"，不自动换别的对象。
- 命令与视角【文档 08】：界面操作都提交为命令，开面板和切视图不是命令。管理界面不隐式改变地图或场景视角。
- 面板清单【文档 08】：车队、线路与施工、聚居地、市场、服务、战斗、报告、通知记录、设置与存档。布局未定，要"先做流程原型再定"。
- 顶栏【文档 08、美术 07】：高 44 px，放倍速（暂停、1×、2×、4×、8×）、实际速度、游戏内时间（天时分）、资金。
- 层级【文档 08】：场景 < 节点小地图 < 业务面板 < 设置与错误。小地图在节点场景右上角、顶栏下方。库存、人口、产量等数字只在窗口显示，节点场景不画数字（#206 输入）。
- 通知【文档 08】：分信息、完成、警告、严重四级。每类可设暂停或降到 1×，默认都关，只有遇敌降到 1×。点击跳到相关对象。
- 宏观地图【文档 08、美术 07】：
  - 2D 俯视，可平移缩放，底图按地貌着色。
  - 线路画平行线，条数等于铁轨数，未建线路画虚线，另有断点和施工标记。
  - 列车 5 种状态（运行、装卸、等待、受阻、战斗）用状态色。
  - 聚居地按关系着色（自有、非敌对、敌对）。
  - 可开关三个信息层：节点资源、世界生物、站台占用。
- 场景切换【文档 08】：地图是中心。点节点进节点场景；点线路或列车进线路场景并跟随；设计编辑器从菜单或车辆面板进入。同一时间只显示一个场景，返回键回地图。打开场景不加阻挡全屏遮罩。失败时回地图并提示原因。
  - 【冲突】#207 的原结论写"显示加载遮罩"，以 08 现文为准。
- 视觉【美术 07】：
  - 状态色全局同色同义，价格涨用完成色、跌用严重色。
  - 面板底 `rgba(24,28,33)`，正文 14 px，标题 16 px 粗体，表格行高 34 px，列表面板宽约 360 px。
  - 主要按钮用强调色 `#e0a22e`。字体是 Noto Sans SC，数字用等宽数字。
  - 物品图标是 icon.png 加界面统一绘制的外框；符号按 24×24 单色线条。
  - 美术 00 的关键词（功能优先、节制）没有直接写 UI 规则。
- 设计编辑器【文档 15】：占用当前场景，进入即暂停世界。有单格、笔刷、长方体三种工具，可按高度剖切，撤销重做不限步数。操作超过 512 格要确认，关闭未保存时提示。缺失内容要显示标识和包名。
- 提示原则【文档 00、18】：失败原因要清楚；缺失或不可用不能显示成 0。
- 现状【推断，读自 `Ui/GameUi.cs`】：顶栏是平铺按钮：节点、线路、车队、存档、经营报告、战斗、通知、设置、新建设计…、蓝图库…。
