# 外壳与世界画面 UI 盘点（只读，行号为当前 master）

标注“推测”的是由代码常量推算，未运行验证。

## 1. 全局

**窗口**（project.godot:25-28）：视口 1920×1080，canvas_items + expand，没有最小窗口限制。界面缩放 0.75–2.0（SettingsPanel.cs:96）。全仓库没有音频节点。界面和菜单都不显示版本号。

**启动流程**：
- App.tscn 只含 MainMenu。启动后自动加载内容（App.cs:120）。加载期间菜单没有提示，只有“新游戏”按钮灰显（GameUi.cs:358）。
- 点“新游戏”，弹出窗口：世界种子默认 `0`，另有生成配置下拉。点“创建对局”后，OnBoundary 隐藏菜单并显示 `_world`（GameUi.cs:444），得到一张暂停的宏观地图。
- 另一条进入路径是菜单的“存档”，读档后进入世界。

**进入世界后的默认元素**（位置和尺寸均为代码内固定像素）：

| 元素 | 位置/尺寸 |
|---|---|
| MacroMap | 全屏，背景 #b7c4a6（亮色），与深色 UI 反差大 |
| 顶栏 | TopWide，HFlowContainer，窄窗口会换行（GameUi.cs:130-143） |
| 顶栏内容，自左到右 | 时钟文本、返回地图（仅 3D 场景）、暂停 1× 2× 4× 8×、节点 线路 车队 存档 经营报告 战斗 通知 设置 新建设计… 蓝图库…，以及仅 Debug 且非重放时出现的“创作…” |
| 地图信息层 | 右上，最小宽 280，三个复选框默认全关 |

3D 场景额外元素：
- 节点小地图：右上，240×200，仅节点场景出现。
- 加载提示：“正在加载场景…”，位置 (16,64)，层 5。
- 血条与状态图标：悬停、选中详情或设置里开启“一直显示”时出现。

**面板共存**（UiStyle.cs:77-156）：
- 全部非模态，数量不限。
- 不能拖动，不能缩放，点击只会置顶。
- 顶栏按钮只“打开或置顶”，不会切换关闭，只能点每个面板的“×”（WorldPanels.cs:95）。Esc 不能关面板。
- 存档、问题反馈、开发检查器是引擎子窗口，可拖动。存档窗口是 Exclusive（模态）。
- 设计编辑器打开时，业务面板被隐藏（GameUi.cs:307-314），但顶栏只禁用了倍速按钮（GameUi.cs:336）。节点、线路、车队、经营报告、战斗、通知这些按钮此时点击无可见效果，也没有提示。
- 遮挡顺序：地图层业务面板 < 通知提示 < 设置、错误、新游戏 < 子窗口 < 控制台（层 128）。

**默认坐标重叠**：
- (24,68)：三个列表（节点、线路、车队）和通知记录。
- (408,68)：对象详情和聚居地面板。
- (310,90)：编组和运行计划。
- 右上 y≈68：Toast（x=宽−480）、错误面板（宽 540）、小地图和地图信息层，互相覆盖。Toast 在 NotificationPanel.cs:102，错误面板在 GameUi.cs:691。

**键鼠操作**：

| 操作 | 作用 | 定义位置 |
|---|---|---|
| ` 或 ~ | 开关控制台（Release 也有） | GameConsole.cs:89-170 |
| Esc | 控制台开着时关闭控制台 | GameConsole.cs:101 |
| Esc | 3D 场景可见且未被界面消耗时返回地图 | WorldSceneView.cs:138 |
| Esc | 设计编辑器关闭（`editor_close`） | project.godot:62, DesignEditorPanel.cs:277 |
| Ctrl+Z / Ctrl+Y / Ctrl+S | 编辑器撤销/重做/保存草稿 | project.godot:44-60 |
| Ctrl+Shift+R | 重载内容（仅 Debug） | App.cs:187 |
| 地图左键 | 点击对象，优先级：战斗、列车、节点、边 | MacroMap.cs:154 |
| 地图滚轮 | 以光标为中心缩放，每格 ×1.2，范围 fit/8 到 fit×8 | MacroMap.cs:146 |
| 地图中键拖动 | 平移 | MacroMap.cs:145 |
| 3D 左键 | 拾取，弹出详情 | WorldSceneView.cs:143 |
| 3D 右键拖动 | 环绕，俯仰 0.15–1.35 rad | WorldSceneView.cs:150 |
| 3D 中键拖动 | 平移 | WorldSceneView.cs:151 |
| 3D 滚轮 | 缩放，距离 8–240，节点场景上限 96 | WorldCamera.cs:146 |

冲突与缺失：
- Esc 有三种含义。设置、存档、详情等面板不消耗 Esc，所以打开设置时按 Esc，会在 3D 场景里直接返回地图（代码推断）。
- 没有暂停、倍速、存档、读档的快捷键，没有键位设置，没有键盘平移相机。没有中键的设备无法平移地图。
- Ctrl+S 只对编辑器草稿有效，对游戏存档无效。
- 地图没有“回到全图”按钮。fit 只在世界几何变化时重算（MacroMap.cs:129）。

## 2. 视觉基础

**Theme.tres**：
- 字号：默认 14，Title 16（粗），主菜单标题 48，地图节点名 15，图例 12，小地图标题 14。
- 字体：Noto Sans SC 常规和粗体，各约 8 MB。UiStyle.NumericFont 设置了 `tnum`（UiStyle.cs:60），但 Fonts/README 说明字体没有该特性，且决定不使用。
- 面板：背景 #181C21，边框 #3B434D，圆角 4，边距 12/8，顶栏边距 12/3，顶栏背景 alpha 0.92。
- 按钮：主色琥珀 #E0A22E，悬停 #EDB54B，按下 #C98C20，文字深色 #1A1A1A。
- 按钮状态：次级按钮透明底，描边；禁用样式与常态相同，只改字色 #9AA3AD，区分度低。
- 输入框背景 #111620；分隔线 #2C333B。
- 间距：窗口内 `Layout` 间距 12，`Body` 间距 10，顶栏水平间距 12。
- 控件尺寸：按钮最小高 34，输入框和下拉高 38，下拉和 SpinBox 280×38。

**语义色**（UiStyle.cs:8-15）：
- Error #C9423A，Warning #D8962A，Success #2F9E5C，Info #7F8FA3。
- Servicing #2AA3B3，自有 #2B77D0，中立 #7F8893。

**图标**（Ui/Symbols，共 10 个 48×48 PNG）：
- lair
- notification-info / complete / critical
- train-running / servicing / waiting / combat / retreating
- warning

图标在地图和血条上缩到 14–20 px。货物图标由 GoodIcon 着色器绘制。

## 3. 逐个视图

**主菜单**（MainMenu.cs + .tscn）：
- 按钮从上到下：新游戏、从示例开始（仅 Debug）、设置、退出、存档。
- “存档”排在“退出”之后，尺寸 240×48，其他按钮 300×44。
- 初始焦点在“退出”（MainMenu.cs:55），启动后按回车就退出。

**新游戏**（GameUi.cs:577-640）：
- 种子默认 0，每次进入同一个世界，没有“随机”按钮。
- 点击“创建对局”后，面板上“创建对局”灰显，“取消”和右上“×”仍可用，点取消会撤销创建。
- 缺失内容时出现“确认继续”。反馈同时写在面板内的 `Problem` 标签和右上错误面板里。

**存档窗口**（SavePanel.cs，680×460）：
- 状态行直接显示 GUID：`名称 · {Guid} · 未保存`（:139）。
- 列表项是“名称 · 时间 · 自动”，没有预览。没有 ItemActivated，不能双击读取，必须先选中再点“读取选中存档”。没有删除和重命名。
- 第一行按钮：读取选中存档、读取最近存档、导入文件。会话中另有一行：保存、另存为、导出文件、返回菜单。忙碌时出现“取消当前操作”。
- “返回菜单”藏在“存档”窗口里，和保存按钮同一行，层级不直观。
- 离开确认有三个选项（保存、不保存、取消）。
- 提示文案含“核心已冻结，不能保存”（:141）。导入导出用引擎内置文件对话框；问题反馈用原生对话框（IssueReportPanel.cs:23），不一致。

**设置**（SettingsPanel.cs，居中，宽 576）：
- 窗口模式、画质（中/高）、界面缩放、帧率上限、失焦时自动暂停（默认关）、镜头抖动、一直显示血条和状态图标、自动存档（默认 60 分钟）。
- 通知部分：16 类事件，每类一个下拉（不响应、降到 1×、暂停），共 16 行（:123-134）。只有“遇敌”默认为“降到 1×”，其余默认“不响应”。
- 全部设置改动立即生效并写盘；内容约 1300+ px（推测），靠内部滚动。
- 底部有“报告问题”（打开子窗口）和“返回”。设置不能在世界里重复点开切换。
- 没有镜头灵敏度、键位、音量设置。

**报告问题**（IssueReportPanel.cs）：
- 设置里的第二层窗口，非模态。
- 内容：录制状态、范围、缺口、证据目录路径、“导出复现 ZIP”、“打开证据目录”。
- “缺口”“起点”这类词偏开发者术语，比如 `step:sequence` 位置格式。

**通知**（NotificationPanel.cs + App/Notifications）：
- Toast：右上堆叠，每条 420×64，6 秒真实时间后消失。数量没有上限（:69）。
- 记录面板：“通知”按钮打开，固定在 (24,68)，宽 460。过滤复选框（信息、完成、警告、严重）只保留在本次运行。记录没有条数上限，“通知”按钮没有未读标记。
- 点击一条通知，会离开宏观地图并打开对应位置的 3D 场景；对象不存在时只提示“已不存在”（GameUi.cs:490-523）。
- 颜色：白字配 Warning/Info 色，对比度按 WCAG 公式估算约 2.5:1 和 3.3:1，低于 4.5:1。

**场景状态覆盖层**（SceneStatusOverlay.cs）：
- 悬停、选中或开启“一直显示”时，在对象头顶画 16 px 图标和 48×6 血条。
- 血条阈值：≥50% 绿，≥25% 琥珀，其余红。
- 悬停被界面遮住时不显示。

**世界面板**（WorldPanels.cs）：
- 列表：宽 360，搜索框，ItemList 328×340。名称基于 ID，如“列车 3 · 运行”“线路 5 · A—B”。提示文字“点列表打开详情，不改变当前视角。”（:104）。
- 详情：宽 420，位置固定 (408,68)，同位置堆叠。内容是 Label 文本块，在 390×340 里滚动；不能定位到地图。含原始内容 ID，如 `core:plains`（:318, :333）。
- 详情按钮：
  - 节点：编组、库存、市场与服务…、战斗…、建立聚居地…，外加每辆车的“改装车辆 N…”“车辆 N 服务…”。
  - 线路：铁路施工…。
  - 列车：列车库存…、战斗…、编辑计划、启动、停车、解编…，外加每辆车的“改装车辆 N…”“车辆 N 服务…”。
- “编辑计划”和“启动”都是主色。长编组会生成很多按钮。
- “…”后缀用法不一致：“编组”“编辑计划”也是打开面板，却没有后缀。
- 解编有确认对话框；启动、停车直接提交，没有确认。

**宏观地图**（MacroMap.cs）：
- 左键点击进入对象的 3D 场景，不是打开详情。只有线路和空节点会同时弹出详情（GameUi.cs:464）。聚居地和巢穴节点要靠节点列表查详情。
- 点战斗标记会打开该位置的 3D 场景，不会打开战斗面板（GameUi.cs:482-488）。
- 同一节点上的列车画在同一偏移点（MacroMap.cs:414），上面的会盖住下面的，下面的只能从车队列表访问，而列表不能进入跟随。
- 空节点半径 6 px，边的点击容差 6 px。没有悬停提示，没有悬停高亮。
- 信息层默认关，三个选项：节点资源、站台占用、世界生物，每项带 12 px 图例说明。

**节点小地图**（NodeMinimap.cs）：
- 只有节点场景有，边场景没有。240×200，无图例，只有 Tooltip：“单击或拖动定位；跟随列车时切换为自由相机”（:35）。
- 点击会改变跟随状态，这一点只写在 Tooltip 里。

**相机与跟随**（WorldCamera.cs, FollowedVehicle.cs）：
- 跟随的是编组几何中心所在的那辆车。
- 跟随时平移被静默忽略（WorldCamera.cs:168）。取消跟随只能点小地图或返回地图。
- 进入跟随只有两条路：宏观地图点列车，或点列车通知。详情面板没有“跟随”按钮。

**控制台**（GameConsole.cs）：
- 底部全宽，高 360，背景 alpha 0.92，输入框占位符 `help`。没有任何按钮可以打开，玩家只能靠 ` 键发现。
- Release 只有 help、clear、quit、loglevel；Debug 另有 reload、sim、train、lighting、dev。

**开发检查器**（DeveloperInspector.cs）：
- 仅 Debug，用 `dev` 打开，子窗口 900×700，非模态。
- 五个标签页：推进与重放、对象、命令、检查点与标记、场景与性能。
- 大量原始调试字段。

**错误面板**（GameUi.cs:225, :684）：
- 所有错误共用标题“操作未完成”，同时只有一条，后一条覆盖前一条，不会自动消失。
- 文案含“宿主”（:403）。场景失败直接显示 `{code}：{detail}`（:555）。

**TrainPlanInput.cs**：
- 校验失败共用一条笼统提示，含“ID”“模拟步数”（:18）。

**倍速与时钟**（GameUi.cs:332-337, :477-479）：
- 时钟文本：`第N天 HH:MM   运行中   实际 0.98×   资金 N`。资金没有单位和千分位，“实际 ×”含义不明。
- 暂停原因括号里是“失焦、编辑、处理中、故障”。
- “暂停”是 ButtonGroup 成员，再点它不会恢复，只能点某个倍速。
