# 06 磨损、损伤、动画与特效

> 决策出处：美术 Q190、Q212、Q216、Q219、Q225、Q238。磨损的程度和画法、表面损伤、部件被毁与摧毁、铁轨断点与工地、特效的风格与强度上限、动画规则、轮对、贴花和各阶段范围，由[磨损、损伤、动画与特效](https://github.com/odradekk/train/issues/251)于 2026-10-09 确认；磨损、损伤和动画的原则从[美术方向初稿](../research/art-direction-draft-2026-10-08.md)第 10 节改写。

## 边界

本文规定常态磨损、损伤、特效和动画的视觉规则。损伤怎样由核心状态驱动（结构耐久比例、破损顺序、移除量上限、冒烟和起火的阈值）见设计文档 [01 的场景中的结构破损](../design/01-voxel-engine-and-scenes.md#场景中的结构破损)，部件耐久、结构耐久和摧毁见 [03](../design/03-vehicles-buildings-and-designs.md#部件与结构)，磨损叠加和轮对的渲染规则见 [07](../design/07-rendering.md)，本文引用、不重述。贴图画法见 [02](02-materials-and-textures.md)，涂装见 [03](03-color-and-paint.md)，辉光等效果的总清单见 [05](05-lighting-and-readability.md#效果清单)，血条和状态图标见设计文档 [08](../design/08-window-and-ui.md#常驻控件)。

## 不变量

1. **磨损和损伤分开。** 磨损是长期服役留下的痕迹，纯表现，不代表剩余耐久；修理不擦掉磨损。损伤只由核心状态驱动（美术 Q190、Q219）。
2. **损伤服从核心状态。** 不为了好看毁掉完好的部件，也不让已被毁的设备看起来还在工作。重新打开场景时按核心状态重建，看到的损伤相同；核心里没有的东西，例如残骸和弹坑，场景里也不留（设计文档 01、03）。
3. **效果不能遮住状态。** 磨损、损伤和特效再重，也要看得出是什么部件、什么材质、哪条铁轨断了（[05](05-lighting-and-readability.md) 不变量 3）。
4. **表现不影响模拟。** 动画和特效只读取核心状态；纯装饰的运动不改变模拟（美术 Q238）。
5. **运动范围严格内接。** 单格里会动的部分，整个运动范围都在格内；跨格的运动由复合体整体运动或专用表现完成（美术 Q212、Q238，[01](01-construction-language.md)）。

## 规则

### 常态磨损

- 程度适中：长期服役，但一直有人维护（美术 Q190）。磨损集中在说得通的位置：下部、棱边、踏脚、设备周围；大部分表面仍以底色和材质为主。不锈穿，没有大片锈流。
- 连续的结构不能因为磨损变成每格颜色不同的拼花。
- 所有车辆和建筑的磨损程度相同，新造的也带磨损，不随服役时间加深。同型的车靠随实例身份变化的杂色看起来不完全相同。

| 材质类别 | 磨损 |
| --- | --- |
| 涂装金属 | 棱边和踏脚处掉漆，露出深灰底漆，磨得深的地方露出钢色；下部积灰；开口下方有雨痕 |
| 裸金属 | 暗色氧化和油迹；车轮踏面、钢轨顶面等接触面磨亮 |
| 混凝土 | 水渍、浅色泛碱，边角少量磕碰 |
| 玻璃 | 边缘一圈灰 |
| 橡胶与塑料 | 轻微褪色和积灰 |
| 土石、有机物 | 自然材料，不画磨损 |

掉漆露出的底漆和钢色不随涂装变色，灰尘和油迹叠在涂装上面（[03](03-color-and-paint.md#玩家涂装)）。

### 磨损的画法

- **平铺贴图**：立方体和形状的贴图只画均匀的颜色不均，不画和部位有关的污渍、雨痕或掉漆，否则平铺后每格重复一次（[02](02-materials-and-textures.md#贴图画法)）。
- **磨损叠加**：和部位有关的磨损由渲染时叠加：
  - 按体素在对象里的高度，下部积灰；
  - 朝上的面落尘；
  - 外露的棱边掉漆；
  - 一层低频杂色，随机种子取实例身份，打破平铺的重复。

  车辆、建筑和场景模型（桥、隧道口）按各自的网格叠加，技术规则见设计文档 [07](../design/07-rendering.md#cube-voxel-rendering)。
- **自定义模型**：有自己的 UV，掉漆和积灰直接按部位画在贴图上；磨损叠加只给它加下部积灰和杂色，不另算棱边。
- **场景体素**：地形、道床不加磨损叠加；站台属于站点建筑（[04](04-world-assets.md#进站区域与站台)）。站台混凝土的水渍用均匀的画法画在贴图里。

### 表面损伤

设计文档 01 规定快要被移除的体素和弹孔周围的体素按结构耐久比例加上焦痕、裂纹和变暗。画法：

- 共用一套损伤叠加图，在对象网格里平铺，包含焦黑、裂纹、崩落三种图案。各材质类别用其中几种：

  | 材质类别 | 表面损伤 |
  | --- | --- |
  | 涂装金属 | 焦黑，漆面起泡烧掉，露出钢色 |
  | 裸金属 | 焦黑，受热变色 |
  | 混凝土 | 裂纹，崩掉一块露出骨料，焦黑 |
  | 玻璃 | 放射状裂纹 |
  | 橡胶与塑料、土石、有机物 | 焦黑 |

- 体素被移除后露出的相邻面也算弹孔周围，一样加损伤，所以缺口里面是烧黑的，不是干净的漆面。
- 程度有上限：最重时仍看得出是什么部件、什么材质。
- 受损但未被毁的部件同样用表面损伤表现（设计文档 01）。

### 部件被毁与摧毁

核心里被摧毁的车辆和建筑直接删除，不留残骸（设计文档 [03](../design/03-vehicles-buildings-and-designs.md#部件与结构)、[16](../design/16-settlements.md)）。

- **部件被毁**：按设计文档 01 移除这个体素。命中特效之后，缺口冒一阵烟，几秒后停。
- **车辆被摧毁**：一次大爆炸，有火球、大量碎片和烟柱。车辆随即消失，烟柱再停留一会儿后散掉。
- **建筑被摧毁**：倒塌，扬起尘土和碎片，之后地块变空。
- 这些都不留持久的痕迹：地上没有残骸、焦痕或废墟。

### 铁轨断点与修复中的工地

设计文档 01 规定断点显示为铁轨上的缺口，修复中的断点显示为工地。

- **断点**：
  - 以断点为中心，约 8 米长的钢轨和轨枕不画。钢轨断头平切，不弯曲，剩余部分不移位（设计文档 07）。
  - 道床挖出一个坑，坑边的道床和地面加焦黑。坑只在这条铁轨的道床范围内，旁边完好的铁轨不能看起来也断了。
  - 周围散落几块碎轨枕。
- **桥上的断点**：钢轨和轨枕照样缺一段，桥面加焦黑；不挖坑，桥本身不破。
- **隧道里的断点**：隧道内部不渲染，场景里看不到，位置见宏观地图上的断点符号（[07](07-icons-and-ui.md#宏观地图)）。
- **修复中**：
  - 缺口两端各放一道黄黑相间的路障，黄色用警示黄 `#d9a62b`；旁边堆放新的钢轨和轨枕，放两盏工作灯。没有人，也没有机械。
  - 材料堆放在所有开通铁轨的泰坦净空之外（[04](04-world-assets.md#不变量)）。
  - 修复进度在界面显示，场景里不逐段铺轨；施工动画在 Demo 之后（设计文档 [14](../design/14-construction-refit-and-deconstruction.md)）。

### 特效

- **碎片**：小方块，边长 1/4 格到半格，颜色取被击中体素的材质。和“体素化的几何、写实的材质”一致（美术 Q216、Q225）。碎片的物理只作表现（设计文档 01）。
- **烟、火、火花、闪光**：柔和的写实粒子。
- **射击**：从武器部件画到目标位置（设计文档 01），短促，远处也看得见。每种武器的样子在战斗内容切片时定。
- **设施活动**：运行中的生产设施冒烟、亮灯，表示正在工作，只读取核心中设施的状态（设计文档 [16](../design/16-settlements.md#节点场景)）。
- **漏液**：受损部件处滴落深色液体，属于状态特效（设计文档 01）。
- **生物死亡**：碎片同样用方块，颜色取生物体素的材质（设计文档 01）。
- **灯光闪烁**：工作灯、信号灯、屏幕等发光体，所在部件受损时不规则地闪，频率低；部件被毁时熄灭。画在结构体素上的灯，在结构耐久比例低于起火阈值时开始闪。

### 特效的强度上限

- 闪光只出现在命中点附近，不全屏闪白。任何闪光和闪烁每秒不超过 3 次，这是防止光敏性发作的通行标准。
- 只在玩家正在看的对象被命中时抖动镜头，幅度小，设置中可以关闭（设计文档 [08](../design/08-window-and-ui.md#相机)）。
- 每次命中的碎片数量有上限，几秒内消失，不在地上堆积。
- 持续的烟是半透明的，从损伤处升起后很快变淡，不能长时间盖住整辆车；场景中同时冒烟的处数有上限。
- 火只在局部，只占对象轮廓的一小部分。
- 火、火花和闪光算发光体，可以有辉光（[05](05-lighting-and-readability.md#效果清单)）。
- 具体的数量和时长在实测中调整。

### 动画

- 安装朝向和动画角度是两回事：体素的朝向只有 24 种正交方向，转动的角度只属于表现（美术 Q238）。
- 车辆整体移动只改根变换（设计文档 07）。
- 有玩法意义的状态，例如工作、停机、开火，由核心状态决定，画面只读取；纯装饰的运动不影响模拟。
- 单格里会动的部分（风扇、轴），整个运动范围在格内。模型内部动画按设计文档 07 在 Demo 之后。
- **跨格的转动部件**：多格炮塔、雷达等做成大型设备，整体转动，只改它自己的根变换，转动范围内不能有其他体素。转动范围由设备蓝图声明，安装时扫过的格必须是空的，见设计文档 [03 的复合体嵌套](../design/03-vehicles-buildings-and-designs.md#复合体嵌套)。核心里没有距离和瞄准，炮塔的朝向只是表现，场景按命中事件让它转向目标。
- **车轮**：车轮由渲染器作为“轮对”专用表现生成，按车速转动，可以跨格（设计文档 [07](../design/07-rendering.md#对象渲染)）。转向架的贴图只画侧架和轴箱，不画车轮。转向架体素带 `wheelset` 行为，见[体素定义的格式](../content/voxel.md)。
- **生物**：沿用设计文档 01 的程序动画，例如起伏、扑击；不做骨骼动画。

### 贴花

Demo 不用贴花。损伤和磨损都用着色器叠加：表面损伤由破损顺序决定，重新打开场景结果相同；贴花解决不了平铺重复，跟着车移动也麻烦。标识、编号等玩家标记在 Demo 之后，和多区域涂装、贴花编辑一起做（[03](03-color-and-paint.md#demo-之后)）。

## 本阶段

第一阶段列车采用轮对表现，转向架贴图不画车轮；排布约定在车辆内容实施时确定。第三阶段验证四种磨损叠加与涂装样稿；第四阶段接入静态建设与铁路工地；第五阶段验证损伤、生物程序动画、战斗与断轨恢复视觉样稿；第六阶段交付全部正式资产，包括 11 类特效。范围见[完整 Demo 清单](../content/demo-catalog.md)，各阶段样稿通过不代表正式全目录完成。

历史首个切片只显示整体移动，车轮画在贴图上，未包含磨损叠加、战斗、生物或断轨修复；这些限制不再适用于 Demo。

## Demo 范围

- 磨损叠加：下部积灰、朝上的面落尘、外露棱边掉漆、随实例身份变化的杂色。
- 表面损伤、部件被毁与摧毁的表现、铁轨断点与修复中的工地。
- 碎片、烟、火、火花、闪光、漏液、射击和灯光闪烁，按本文的强度上限。
- 运行中设施的简单活动效果：烟和灯光。
- 轮对：转向架贴图改为不画车轮，车轮由渲染器生成并转动。
- 跨格转动的大型设备，按设计文档 [03 的复合体嵌套](../design/03-vehicles-buildings-and-designs.md#复合体嵌套)实现。
- 生物的程序动画。

## Demo 之后

- 雨痕、油迹、维修留下的色差：需要知道开口和设备的位置。
- 车辆运行中的常态特效，例如排气、刹车火花、扬尘，随各种动力的内容一起定。
- 模型内部动画（风扇、轴）和骨骼动画（设计文档 07）。
- 标识、编号等贴花。
- 修复中逐段铺轨等施工动画（设计文档 14）。
