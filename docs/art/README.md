# 美术设计文档

本目录规定游戏的美术风格和资产制作规则，是这两方面的权威文档：画面整体是什么基调，车辆、建筑、地形和界面怎么画，资产按什么规格制作、怎样检查。本目录由地图[美术设计文档：整理初稿，建成 docs/art](https://github.com/odradekk/train/issues/239)建立，起点是 2026-10-08 美术讨论的整理稿。

## 与设计文档的关系

- [设计文档](../design/README.md)是游戏的设计契约。占格、朝向、内容格式与表现绑定、渲染路径、核心状态等技术规则由设计文档维护；本目录引用这些规则，不重述。
- 本目录在这些技术规则之内规定画法、规格和检查。美术规则需要改动技术规则时，同时修改设计文档的对应章节。
- 规则写成后，资产制作和代码改动另开实施工单，不因本目录发布而扩大当前切片的实现范围。

## 术语

> 决策出处：[美术文档的术语](https://github.com/odradekk/train/issues/241)。

设计文档和代码也会用到的词以 [CONTEXT.md](../../CONTEXT.md) 为准，例如体素、体素格（简称格）、体素定义、结构体素、部件、复合体、大型设备、蓝图、场景模型、形状、标准变体、涂装。本节只定义美术制作中使用的词。

正文用中文术语，词条第一次出现时在括号里附英文。英文只保留在三种地方：代码标识（如 `scene_only`、`voxel_top`）；没有通行中文说法的技术名（如 PBR、UV、Mipmap、Triplanar）；[00](00-direction.md) 中八个关键词的原词。

**自定义模型（Custom Mesh）**：
为某一种体素定义单独制作的模型，对应 [07](../design/07-rendering.md) 的 Custom Mesh。
_Avoid_: 专用件

**子网格**：
建模时参考的 1/8 格网格，用来确定外形比例和接口位置；不是新的占格单位。

**严格内接**：
模型完全位于自己所在的格内，不越出格的边界。

**运动范围**：
会动的部分（风扇、轴、炮塔）在整个动作过程中经过的全部空间。普通体素的运动范围也必须严格内接。
_Avoid_: 扫掠包络

**贴图密度**：
每格边长对应的贴图像素数，例如 32 px/格。
_Avoid_: 纹理密度

**信息贴图**：
铭牌、文字、编号、屏幕等需要清楚可读的贴图，可以不受基础贴图密度限制。
_Avoid_: 信息纹理

**微表面**：
材质上细小的粗糙度和法线变化，用来增加质感，不承载需要读出的信息。

**可涂装区域（Paint Mask）**：
一个体素表面中能被涂装改色的部分；玻璃、裸金属、橡胶、灯具等保留各自的颜色和质感。
_Avoid_: 整体染色

**磨损（Wear）**：
长期服役留下的痕迹，例如灰尘、雨痕、掉漆、油迹；纯表现，不代表剩余耐久。
_Avoid_: 损伤、老化度

**磨损叠加**：
渲染时按部位叠加在贴图上的磨损：下部积灰、朝上的面落尘、外露棱边掉漆，以及打破平铺重复的杂色。平铺贴图本身只画均匀的颜色不均。
_Avoid_: 磨损贴花、磨损层

**损伤（Damage）**：
按核心的耐久状态显示出来的缺口和破损，只能由真实状态驱动。
_Avoid_: 磨损、随机破坏

**样机**：
为验证美术规则而做的车辆或建筑，例如民用重载机车、军用重装车辆、工业维护建筑。
_Avoid_: 原型（指车辆或建筑时）

**原型**：
可运行的实验程序，例如归档中的 HTML 原型。
_Avoid_: 样机

### 初稿用词对照

[美术方向初稿](../research/art-direction-draft-2026-10-08.md)和[美术讨论决定记录](../research/art-grilling-decisions.md)保留了当时的用词，改写时按下表换成现行说法：

| 初稿 | 现行说法 |
| --- | --- |
| 构件 | 指一块时说体素，指一种时说体素定义，指能用的全部时说可用的体素定义 |
| 功能件 | 部件 |
| 结构块、通用造型块 | 结构体素 |
| 复合体、Composite、装配体 | 复合体是总称；具体时说车辆、建筑、大型设备、场景模型或生物，指设计时说蓝图 |
| Shape、Shape Asset | 形状 |
| 专用件 | 自定义模型 |
| Voxel、Cell | 体素、格 |
| 纹理 | 贴图 |
| 扫掠包络 | 运动范围 |
| Paint Mask | 可涂装区域 |
| Wear、Damage | 磨损、损伤 |
| Blueprint Stamp | 不用；大型设备是复合体，整体装上，见[复合体嵌套：大型设备装到车辆和建筑上](https://github.com/odradekk/train/issues/249) |
