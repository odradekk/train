## 本阶段

首个切片没有涂装，颜色直接画在贴图里。下表是各贴图的基色，板缝、百叶、加强筋等图案在基色上加深或提亮。

### 车辆：蓝灰机车、暗红货车

| 用途 | 色值 |
| --- | --- |
| 车体结构：底架、驾驶室下部和车顶、货车车顶 | `#5a6b78` 蓝灰 |
| 动力部件 | `#5a6b78` 蓝灰 |
| 车窗玻璃，画在控制部件上 | `#1e2830` |
| 货舱部件 | `#7b3a2c` 暗红 |
| 转向架 | `#33373b` 石墨灰 |
| 车轮踏面 | `#8e9398` |
| 车底 | `#2b2e31` |

车体结构同时用于车头和货车，所以货车的底架和车顶也是蓝灰。

### 货物

| 用途 | 色值 |
| --- | --- |
| 粮食的麻袋 | `#bfa676` |
| 煤块 | `#232321` 到 `#3d3d39` |
| 棉包 | `#e2ddd0` |
| 棉包的钢捆带 | `#8d9296` |
