# 03 色彩与涂装

> 决策出处：美术 Q189、Q208、Q218、Q222、Q228、Q229。默认色板的色值、可涂装的材质类别、涂装怎样改变外观、推荐色卡和各阶段范围，由[默认色彩与玩家涂装](https://github.com/odradekk/train/issues/250)于 2026-10-09 确认；“本阶段”由[首个切片的体素面贴图规格](https://github.com/odradekk/train/issues/246)于同日确认，色值来自[首个切片车辆贴图样稿](../../archive/prototypes/first-slice-vehicle-textures.prototype.html)的 A 套配色，这些值是历史样稿的初值；调整时同步本文和该批资产的唯一源。

## 边界

本文规定车辆、建筑和设备的默认色彩与玩家涂装的视觉规则。材质类别和贴图画法见 [02](02-materials-and-textures.md)，磨损见 [06](06-wear-damage-and-motion.md)，地形和自然物的颜色见 [04](04-world-assets.md)，宏观地图和界面的颜色见 [07](07-icons-and-ui.md)。涂装属于设计和蓝图的表现设置（设计文档 [02](../design/02-definitions-and-content.md)、[11](../design/11-goods-and-production-network.md)），编辑器中的操作见设计文档 [15](../design/15-design-editor-and-tools.md#编辑)。

## 不变量

1. **颜色不决定玩法。** 涂装和默认色都不改变体素定义、数值、能力或经济身份（设计文档 02、11）。
2. **涂装不改变材质。** 涂装只换颜色，保留贴图的明暗和图案；材质响应不变，高饱和的颜色也不会变成塑料感或发光（美术 Q222）。
3. **默认色板不限制玩家。** 默认色板只约束官方内置设计的方向，玩家可以选任何颜色（美术 Q189、Q229）。
4. **默认外观看得出材料。** 内置设计的颜色克制，看得出车体由什么材料构成（美术 Q189）。

## 规则

### 默认色板

| 类 | 颜色 | 色值 |
| --- | --- | --- |
| 基色 | 蓝灰 | `#5a6b78` |
| 基色 | 钢灰 | `#7e858b` |
| 基色 | 石墨灰 | `#33373b` |
| 基色 | 低饱和橄榄 | `#626750` |
| 基色 | 混凝土色 | `#a8a59e` |
| 强调色 | 米白 | `#d9d4c7` |
| 强调色 | 警示黄 | `#d9a62b` |
| 强调色 | 警示橙 | `#c96a2b` |
| 强调色 | 暗红 | `#7b3a2c` |

- 基色占车体和建筑的大部分。强调色只用在危险部位、边缘、活动部件和标识上，不规定面积比例。
- 图案可以在色值的基础上加深或提亮，色值是基色，不是唯一允许的颜色。
- 工作灯和信号灯是发光体，不属于涂装；工作灯的颜色为 `#ffd9a0`。

### 玩家涂装

以下是[用户在 #338 确认的涂装规则](https://github.com/odradekk/train/issues/338#issuecomment-6235173812)，当前进度见[渲染实现与贴图迁移](#本阶段)。

- 初期每个体素一个主色，支持批量操作（美术 Q208、Q218）。
- 只有材质类别为 `painted_metal` 和 `concrete` 的表面可以涂装；`bare_metal`、`glass`、`stone_soil`、`polymer_rubber`、`organic` 保持原色（美术 Q222，类别见 [02](02-materials-and-textures.md#材质类别)）。
- 立方体面图的 PNG Alpha 表示可涂权重，形状沿用相同规则：255 表示完全可涂，0 表示保留原色，中间值按比例混合。Alpha 不表示透明度；Alpha 为 0 的 RGB 仍是可见颜色，制作、导出和采样时不能清空。与车体画在同一张图上的车窗等保留区，用 Alpha 排除涂装。
- 自定义模型按表面的材质类别划分可涂区域；模型 Alpha 只用于镂空裁剪，不兼作可涂权重。需要保留原色的玻璃等部分分到对应材质类别的表面。
- 可涂部分画成接近白色的中性纹样：原默认色的亮度对应白色，板缝、百叶、加强筋等图案的明暗差保留为更暗的灰阶。保留区仍画自己的固有色。涂装只换颜色，保留这些纹样，不把光照、高光或阴影画进贴图。
- 可涂立方体表面的颜色在线性空间计算：`贴图 × lerp(1, 涂装色, Alpha)`。贴图 RGB 和 `paint` 的 sRGB 色值先转为线性值，Alpha 直接归一化为 0–1 的权重，不做色彩空间转换。即 `C = S × ((1 − a) + a × P)`，其中 `S` 是线性贴图 RGB，`P` 是线性涂装 RGB，`a` 是 Alpha 权重。模型的可涂表面整体乘涂装色，不从模型 Alpha 取权重；不可涂材质类别始终保留原色。
- 可涂体素不写 `paint` 时显示贴图的中性纹样，可涂部分接近白色；内置设计通过 `paint` 显式写入各自默认色，不再把默认色画在可涂部分的 RGB 中。已有实例保存自己的设计，修改蓝图不会为它补色（[设计文档 03](../design/03-vehicles-buildings-and-designs.md#车辆与建筑实例)）。
- 掉漆处露出的底材不随涂装变色；灰尘和油迹叠在涂装上面。磨损的程度和画法见 [06](06-wear-damage-and-motion.md#常态磨损)。
- 选色器提供[本阶段的六张命名推荐色卡](#本阶段)，玩家点选后涂到体素上（美术 Q229）。

## 本阶段

第一阶段的历史配色在迁移后作为各内置设计的默认涂装色，不再作为可涂贴图的固有色。第三阶段验证三台样机的涂装和六张推荐色卡，第六阶段完成正式资产。

选色器使用以下六张命名色卡，色值取默认色板；色块直接由界面代码绘制，不另存 PNG。点选只设置当前主色，涂装仍通过编辑操作应用。

| 色卡 | 色值 |
| --- | --- |
| 民用蓝灰 | `#5a6b78` |
| 货运暗红 | `#7b3a2c` |
| 工程黄 | `#d9a62b` |
| 军用橄榄 | `#626750` |
| 军用石墨 | `#33373b` |
| 工业钢灰 | `#7e858b` |

[#339](https://github.com/odradekk/train/issues/339) 已通过 [#588](https://github.com/odradekk/train/pull/588) 落实 Godot 渲染端的涂装规则：只有 `painted_metal` 和 `concrete` 接受涂装；立方体面图 Alpha 作为可涂权重，Alpha 0 保留原色且不产生透明。模型渲染端按场景提供的各表面材质类别分别决定是否涂装；模型 Alpha 只用于 MASK 镂空裁剪，不作为涂装权重。

[#583](https://github.com/odradekk/train/issues/583) 已将现有 26 个 `painted_metal`／`concrete` 体素定义的可涂贴图迁为中性纹样，并为内置设计和示例存档补齐默认 `paint`。车辆蓝图由创作模式维护。共用面贴图仍由 `scripts/content/generate_small_world.py` 生成，共用图继续引用同一 PNG。#338 的临时样例不成为正式资产源。

每个可涂体素定义只有一个默认色，迁移时沿用原贴图可涂部分的基色；经批准的正式美术批次可以替换占位基色，#393 将建筑材料、混凝土块改为 `CONCRETE`，结构块改为 `STEEL`。这些基色由 `scripts/content/generate_small_world.py` 中的基色常量确定，例如下表车辆体素使用的 `BLUE`、`RED`，以及 `concrete` 使用的 `CONCRETE`（`#a8a59e`）。

默认色只在生成器里维护一份。生成器在输出内置设计前，为引用可涂体素且尚未写 `paint` 的调色板项补默认色，包含嵌套组装体和场景模型中的设计。生成设计沿用体素的默认色；创作模式维护的车辆蓝图在自身调色板中保存涂装方案；已经显式写入的 `paint` 保持不变，包括 `tunnel-portal-*` 的 `#000000`。Scenes 直接放置的可涂原料使用生成器输出的内部色表，当前只有原油资源堆。

按[用途倾向](#用途倾向)给具体设计换涂装方案，由制作该设计的美术工单（如 [#391](https://github.com/odradekk/train/issues/391)）在它自己的蓝图里修改。

模型体素 `SurfaceMaterials` 到场景模型材质列表的生产投影已由 #388 完成，原样保持表面次序并传递该格涂装；Godot 按该列表设置各表面的材质。
