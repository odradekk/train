# 03 色彩与涂装

> 决策出处：美术 Q189、Q208、Q218、Q222、Q228、Q229。默认色板的色值、可涂装的材质类别、涂装怎样改变外观、推荐色卡和各阶段范围，由[默认色彩与玩家涂装](https://github.com/odradekk/train/issues/250)于 2026-10-09 确认；“本阶段”由[首个切片的体素面贴图规格](https://github.com/odradekk/train/issues/246)于同日确认，色值来自[首个切片车辆贴图样稿](../../archive/prototypes/first-slice-vehicle-textures.prototype.html)的 A 套配色，调整时样稿与本文一起改。

## 边界

本文规定车辆、建筑和设备的默认色彩与玩家涂装的视觉规则。材质类别和贴图画法见 [02](02-materials-and-textures.md)，磨损见 06，地形和自然物的颜色见 [04](04-world-assets.md)，宏观地图和界面的颜色见 [07](07-icons-and-ui.md)。涂装属于蓝图的表现设置（设计文档 [02](../design/02-definitions-and-content.md)、[11](../design/11-goods-and-production-network.md)），编辑器中的操作见设计文档 [15](../design/15-design-editor-and-tools.md#编辑)。

## 不变量

1. **颜色不决定玩法。** 涂装和默认色都不改变体素定义、数值、能力或经济身份（设计文档 02、11）。
2. **涂装不改变材质。** 涂装只换颜色，保留贴图的明暗和图案；材质响应不变，高饱和的颜色也不会变成塑料感或发光（美术 Q222）。
3. **默认色板不限制玩家。** 默认色板只约束官方内置设计的方向，玩家可以选任何颜色（美术 Q189、Q229）。
4. **默认外观看得出材料。** 内置设计的颜色克制，看得出车体由什么材料构成（美术 Q189）。

## 规则

### 默认色板

| 类 | 颜色 | 色值 |
| --- | --- | --- |
| 基色 | 蓝灰 | `#5a6b78` |
| 基色 | 钢灰 | `#7e858b` |
| 基色 | 石墨灰 | `#33373b` |
| 基色 | 低饱和橄榄 | `#626750` |
| 基色 | 混凝土色 | `#a8a59e` |
| 强调色 | 米白 | `#d9d4c7` |
| 强调色 | 警示黄 | `#d9a62b` |
| 强调色 | 警示橙 | `#c96a2b` |
| 强调色 | 暗红 | `#7b3a2c` |

- 基色占车体和建筑的大部分。强调色只用在危险部位、边缘、活动部件和标识上，不规定面积比例。
- 图案可以在色值的基础上加深或提亮，色值是基色，不是唯一允许的颜色。
- 工作灯和信号灯是发光体，不属于涂装；工作灯的颜色为 `#ffd9a0`。

### 用途倾向

不是硬性限制，只是内置设计的起点：

| 用途 | 倾向 |
| --- | --- |
| 民用 | 蓝灰、钢灰；货车可用暗红 |
| 军用 | 低饱和橄榄、石墨灰 |
| 工业与工程 | 钢灰加警示黄 |
| 建筑 | 混凝土色、钢灰、暗红 |

### 玩家涂装

- 初期每个体素一个主色，支持批量操作（美术 Q208、Q218）。
- 只有材质类别为 `painted_metal` 和 `concrete` 的表面可以涂装；`bare_metal`、`glass`、`stone_soil`、`polymer_rubber`、`organic` 保持原色（美术 Q222，类别见 [02](02-materials-and-textures.md#材质类别)）。
- 涂装只换颜色，板缝、百叶、加强筋等图案和明暗保留。
- 掉漆处露出的底材不随涂装变色；灰尘和油迹叠在涂装上面。磨损的程度和画法见 06。
- 选色器提供一组命名的推荐色卡，例如民用蓝灰、货运暗红、工程黄、军用橄榄、军用石墨、工业钢灰，玩家点选后涂到体素上（美术 Q229）。

## 本阶段

首个切片没有涂装，颜色直接画在贴图里。下表是各贴图的基色，板缝、百叶、加强筋等图案在基色上加深或提亮。

### 车辆：蓝灰机车、暗红货车

| 用途 | 色值 |
| --- | --- |
| 车体结构：底架、驾驶室下部和车顶、货车车顶 | `#5a6b78` 蓝灰 |
| 动力部件 | `#5a6b78` 蓝灰 |
| 车窗玻璃，画在控制部件上 | `#1e2830` |
| 货舱部件 | `#7b3a2c` 暗红 |
| 转向架 | `#33373b` 石墨灰 |
| 车轮踏面 | `#8e9398` |
| 车底 | `#2b2e31` |

车体结构同时用于车头和货车，所以货车的底架和车顶也是蓝灰。

### 货物

| 用途 | 色值 |
| --- | --- |
| 粮食的麻袋 | `#bfa676` |
| 煤块 | `#232321` 到 `#3d3d39` |
| 棉包 | `#e2ddd0` |
| 棉包的钢捆带 | `#8d9296` |

## Demo 范围

设计编辑器中每个体素选一个主色，支持批量操作，带推荐色卡（设计文档 [15](../design/15-design-editor-and-tools.md#编辑)）。

## Demo 之后

副色、条纹、标识区等多区域涂装，贴花，一键给整车配色（按体素种类自动分配主色和强调色）。

## 开放问题

- 地图迷雾（不立票）：涂装数据放在蓝图的哪里，只有颜色贴图时可涂装区域怎样编码，首个切片中把默认色画在图里的贴图怎样接入涂装（按“保留明暗、换颜色”重新着色，或把可涂装部分重画成中性色）。设计编辑器切片临近时再定。
