# 02 材质与贴图

> 决策出处：美术 Q190、Q196、Q206、Q217、Q221–Q223、Q225、Q231–Q232。贴图方向、正面图、平铺跨度、贴图密度在格式中的位置、图标、材质类别和采样，由[立方体体素的面贴图形式](https://github.com/odradekk/train/issues/243)于 2026-10-09 确认；形状与自定义模型的贴图由[非立方体形状与构造语言](https://github.com/odradekk/train/issues/245)于同日确认；首个切片的规格由[首个切片的体素面贴图规格](https://github.com/odradekk/train/issues/246)于同日确认；其余从[美术方向初稿](../research/art-direction-draft-2026-10-08.md)第 6 节改写。

## 边界

本文规定体素表面的材质与贴图：材质类别、贴图画法、面与方向、平铺、形状与自定义模型的贴图、贴图密度、采样和细节层次。表现格式与校验见设计文档 [02](../design/02-definitions-and-content.md#表现资产校验)，贴图方向与平铺坐标的技术规则见 [07](../design/07-rendering.md#cube-voxel-rendering)，本文引用、不重述。光照与效果见 [05](05-lighting-and-readability.md)，色彩见 03，磨损和损伤见 [06](06-wear-damage-and-motion.md)。形状和自定义模型的外形规则见 [01](01-construction-language.md)。

## 不变量

1. **贴图只画固有色。** 明暗、阴影、高光都由引擎光照产生，见 [05](05-lighting-and-readability.md#不变量)。
2. **基础贴图密度是 32 px/格**（美术 Q217）。只有信息贴图可以更高（美术 Q231）。
3. **材质类别只决定光照响应。** 类别和颜色都不决定玩法属性；同一类别的体素不因此获得共同的耐热、导电或防护数值。
4. **贴图随对象移动。** 平铺位置按对象自己的网格计算，贴图不会在行驶的列车上滑动。
5. **运动中稳定优先。** 远处用 Mipmap 和各向异性过滤，近处用线性过滤；不把画面强制做成像素风（美术 Q223）。

## 规则

### 材质类别

每个体素定义的表现选一个材质类别（美术 Q221）。类别对应的粗糙度和金属度由渲染层维护，在标准光照下调定，不写进内容。

| 类别 | `material` 取值 | 用途与制作关注 |
| --- | --- | --- |
| 涂装金属 | `painted_metal` | 车体、设备外壳；漆面质感、磨损后露底、拼接关系。不填时的默认值 |
| 裸金属 | `bare_metal` | 钢轨、车轮、加工件；反射与粗糙度有差异，不一律镜面 |
| 混凝土 | `concrete` | 站台、基础、墙体；哑光，块面变化克制 |
| 岩土 | `stone_soil` | 地形、岩层、煤；地质颜色和低频纹样 |
| 玻璃 | `glass` | 车窗、观察窗；Demo 之前按不透明的深色反光面表现 |
| 聚合物与橡胶 | `polymer_rubber` | 护套、密封件、软连接；低反光 |
| 有机物 | `organic` | 木材、植被、粮食与作物 |

写实靠不同材料在同一光照下的反光差异，不靠在每块表面堆污渍、划痕或强镜面（美术 Q225）。新增类别要改内容格式，提出时先说明现有类别为什么不够。

### 贴图画法

- 只画材料的固有色和纹样。立方体和形状的贴图只画均匀的颜色不均；和部位有关的磨损（积灰、掉漆）由渲染时的磨损叠加画出，自定义模型可以按部位画在自己的贴图上，见 [06](06-wear-damage-and-motion.md#磨损的画法)（美术 Q190）。
- 平铺的贴图四边必须能无缝相接。
- 连续的结构（地形、墙体、大块混凝土）用 2–8 格的平铺跨度，不显出格线。需要看出模块边界的结构（装甲板、检修板、设备外壳）用跨度 1，边界用画出的接缝、板厚和材料变化表达，不画统一的黑色格线（美术 Q196、Q206）。

### 面与方向

- 每种立方体体素有顶面、底面、侧面三张图，另可加一张正面图。正面是体素的 Forward 面，用来画车头前窗、设备面板、货舱门这类只在一面出现的内容；不画正面图时，这一面使用侧面图。背面需要不同时，把体素转 180° 摆放。
- 侧面图的上方朝体素的上方，顶面和底面图的上方朝体素的正面；贴图随体素的朝向一起转。画侧面图时按“图的上方就是体素的上方”来画。
- 物品图标单独绘制，不由体素外观生成；画法见 07-icons-and-ui。

### 平铺

体素定义可以声明平铺跨度 1、2、4 或 8 格。跨度为 N 时，一张图覆盖 N×N 格，相邻的同种体素连成一片；位置按体素所在对象的网格计算。正面图不平铺。

### 形状与自定义模型

- 形状沿用所属体素定义的顶面、侧面、底面、正面图、平铺跨度和材质类别，贴图按对象网格投影到形状表面，所以同种材料的立方体和楔形接在一起时贴图连续。斜面取法线最接近的那个轴对应的图，正好在两轴之间时取顶面图或底面图。
- 自定义模型用自己的 UV 贴图，基础贴图密度同样是 32 px/格，只画固有色。一个模型可以分几个表面，例如涂装外壳和玻璃窗，每个表面选一种材质类别。

### 贴图密度与尺寸

- 图的边长等于 32 × 平铺跨度：跨度 1 用 32×32，跨度 4 用 128×128。
- 信息贴图（正面图上的铭牌、编号、屏幕、文字）可以用更高的密度，例如 64 或 128 px/格。这个例外不允许普通钢板、地面或装甲提高密度。
- 内容校验只检查格式：正方形、边长为 2 的幂、顶面、侧面、底面三张图同样大小。像素密度由美术检查把关。

### 采样

近处用线性过滤，远处用 Mipmap 加各向异性过滤。不做全屏像素化；像素风的预览只作为观察模式。

### 细节层次

| 层次 | 承担的信息 | 手段 |
| --- | --- | --- |
| 大形 | 车体大小、装甲倾角、开口、设备轮廓 | 体素的组合与几何 |
| 中层 | 涂层差异、污迹、接缝、明显磨损 | 32 px/格的固有色贴图 |
| 材质响应 | 金属、漆面、混凝土、玻璃的反光差异 | 材质类别 |
| 信息 | 铭牌、编号、屏幕 | 正面图上的信息贴图 |

### 画法要求

- **平铺切开。** 贴图从对象网格的原点开始平铺，面的大小和位置不一定与跨度对齐。在不能保证对齐的方向上，图案保持均匀：百叶上下贯通，窗带上下不画边框，加强筋只沿长度方向变化。顶面图会随体素的朝向转动，所以顶面图案在两个方向上都一样，例如花纹钢板、方格散热网。
- **车轮要对齐。** 只有车轮需要对齐：转向架按 01 侧视图的位置摆放，不能挪动奇数格，否则车轮会被切开。
- **不用正面图。** 首个切片不用正面图，车头的前后靠驾驶室的位置区分。
- **磨损。** 只画轻微的颜色不均，不画和位置有关的污渍、雨痕或掉漆：平铺后它们会在每一行重复出现。这类磨损由 [06](06-wear-damage-and-motion.md#磨损的画法) 的磨损叠加在 Demo 画出。
- **不画信息贴图。** 铭牌、编号这类信息贴图首个切片不画。
