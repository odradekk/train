# 07 图标与界面

> 决策出处：由[宏观地图、界面与图标的视觉风格](https://github.com/odradekk/train/issues/244)于 2026-10-09 确认。色值和尺寸来自[宏观地图与界面风格样稿](../../archive/prototypes/macro-map-ui-style.prototype.html)，调整时样稿与本文一起改。

## 边界

本文规定宏观地图、界面面板、字体、状态色和 2D 图标的视觉规则。地图上显示哪些信息、有哪些面板、怎样交互，见设计文档 [08](../design/08-window-and-ui.md)；本文不规定面板布局和交互。场景中的血条和状态图标沿用本文的状态色。文中的像素尺寸指 1920×1080 下的屏幕像素。

## 不变量

1. **信息优先。** 宏观地图用平涂的制图风格，不画写实地形。
2. **状态色全局统一。** 关系、列车状态、通知等级和警告，在地图、面板和场景标记中同色同义。
3. **不只靠颜色区分。** 每种状态同时用形状、描边或符号区分，色弱玩家也能分辨。状态色避开地貌底色的色相。
4. **物品图标由两部分组成。** 内容中的 icon.png 只画物品本身；外框、底色、数量和状态由界面统一绘制。

## 规则

### 状态色

| 用途 | 状态 | 色值 |
| --- | --- | --- |
| 关系 | 自有 | `#2b77d0` |
| 关系 | 非敌对 | `#7f8893` |
| 关系 | 敌对 | `#c9423a`，另加一圈虚线 |
| 列车 | 运行 | `#2f9e5c` |
| 列车 | 装卸 | `#2aa3b3` |
| 列车 | 等待 | `#d8962a` |
| 列车 | 故障 | `#c9423a`，另加警告符号 |
| 通知 | 信息 | `#7f8fa3` |
| 通知 | 完成 | `#2f9e5c` |
| 通知 | 警告 | `#d8962a` |
| 通知 | 严重 | `#c9423a` |
| 强调色 | 当前选择、主要按钮、选中 | `#e0a22e`，其上文字 `#1a1a1a` |

价格等数值上涨用完成色，下跌用严重色。

### 宏观地图

| 元素 | 画法 |
| --- | --- |
| 地貌底色 | 平原 `#bccf93`、丘陵 `#cbb37e`、森林 `#7aa06a`、荒漠 `#e5cf95`、山地 `#a69d92`；地图以外 `#b7c4a6`；分区边界 1 px `#00000022` |
| 线路 | 每条铁轨画一条 2 px 的 `#2a2a2a` 线，几条铁轨就画几条平行线，间距 5 px；下面衬一条白色衬边（单轨 7 px，双轨 11 px） |
| 施工中的线路 | 警告色虚线，线路中点放施工符号 |
| 断点 | 线路中点放严重色圆圈和断点符号 |
| 聚居地 | 白底圆形，外圈 3 px 关系色，内画占据者类型符号（关系色）；城市半径 20 px，其他 16 px |
| 空节点 | 半径 6 px 的小圆，铁轨色描边 |
| 地名 | `#1e1e1e` 粗体 15 px，4 px 白色描边 |
| 列车 | 28×14 px 胶囊形，填运行状态色，深色描边，白色箭头指示方向 |
| 战斗 | 面板底色圆形，敌对色边框，内画战斗符号 |

### 面板、顶栏与通知

- 面板：底色 `rgba(24,28,33,0.90)`，边框 `#3b434d`，表格行分隔 `#2c333b`，圆角 4 px。
- 文字：正文 `#e6e9ec` 14 px；标题 16 px 粗体；次要文字和表头 `#9aa3ad` 12 px。表格行高 34 px；列表类面板宽约 360 px。
- 按钮：主要按钮用强调色底和深色字；次要按钮透明底加边框。
- 顶栏：高 44 px，底色 `rgba(24,28,33,0.92)`；当前倍速按钮用强调色。
- 通知：面板底色，左侧 4 px 的等级色条，等级标签用等级色底。

### 字体

使用开源字体 Noto Sans SC（思源黑体，OFL 许可），常规和粗体两种字重，随游戏打包，不依赖系统字体。资金、时间、倍速、价格、数量等数字用等宽数字，变化时不跳动。

### 物品图标

**icon.png 的绘制规则**（手工绘制为主，也可以用工具生成，规则相同）：

- 源图 128×128，背景透明，不画外框和底板。
- 物品画在中间约 100×100 的安全区内，四周留边。
- 四分之三视角，光从左上来。图标是 2D 插画，可以画光影，“贴图只画固有色”只约束体素贴图。
- 物品外轮廓用一圈深色线。
- 缩到 32 px 时只靠大形状和固有色就能认出，不依赖细节和文字。

**外框**（界面统一绘制，货物和部件相同）：

- 圆角方框，圆角为边长的 11%；底色从上到下由 `#e3e7ea` 渐变到 `#c2c9d0`；边框 `#6b7580`，宽为边长的 3%。
- 物品缩放到边长的 78%，居中放在外框内。
- 常用显示尺寸 32、48、64 px。

**外框状态与数量**：

| 内容 | 画法 |
| --- | --- |
| 数量 | 右下角，粗体等宽数字，深色字加白色描边；不画进 icon.png |
| 悬停 | 边框加深为 `#3f4751` |
| 选中 | 边框换成强调色，宽为边长的 6% |
| 不可用 | 整体去饱和，不透明度 45% |

### 地图与界面符号

单色线条图形，按 24×24 网格绘制，线宽 2，圆端圆角；按状态色或正文色着色。占据者的每种类型（农庄、煤矿、种植园、村镇、工业镇、市镇、城市）各有一个符号，另有列车、战斗、暂停、播放、警告、断点、施工等符号。
