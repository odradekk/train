# 05 光照与可读性

> 决策出处：美术 Q186、Q223、Q226–Q228、Q230。渲染器、效果清单、色调映射、首个切片的光照与贴图不画光影，由[Compatibility 渲染器下的画面目标](https://github.com/odradekk/train/issues/242)于 2026-10-09 确认，结论是改用 Forward+；可读性规则由该票从[美术方向初稿](../research/art-direction-draft-2026-10-08.md)第 9 节改写。

## 边界

本文规定局部场景的光照、天空与雾、后处理效果、色调映射和画面可读性。渲染器为 Forward+，理由见 [ADR-0010](../adr/0010-render-with-forward-plus.md)。材质参数与贴图见 [02](02-materials-and-textures.md)，色彩见 [03](03-color-and-paint.md)，渲染路径见 [07](../design/07-rendering.md)，性能目标见 [00 的本阶段性能目标](../design/00-product-and-core-loop.md#本阶段性能目标)。宏观地图和界面的视觉见 [07](07-icons-and-ui.md)。

## 不变量

1. **正常光照下就要看得清。** 形体和材质在普通日光下必须成立，不靠暗光、雾或逆光撑气氛（美术 Q227）。
2. **光影由引擎产生。** 贴图只画材料的固有色，不画明暗、阴影和高光；接缝处的污渍属于固有色，可以画。往贴图里画光影会和引擎光照叠加，换光照或转方向就会穿帮。
3. **效果不能遮住状态。** 雾、辉光、阴影和后处理服务于可读性，不能让玩家看不清车辆、设备和损伤的状态。
4. **不用全局黑色描边。** AO 适度，不把缝隙压成黑洞（美术 Q226）。选中框、错误提示和调试网格属于界面，不受这条限制。
5. **默认画质保证帧率。** 默认画质只开必要效果，在目标配置上达到设计文档 [00 的本阶段性能目标](../design/00-product-and-core-loop.md#本阶段性能目标)；较重的效果做成画质选项。

## 规则

### 效果清单

| 效果 | 默认画质 | 说明 |
| --- | --- | --- |
| 方向光阴影（分级） | 开 | 形体靠明暗面读出 |
| 软阴影（PCSS） | 画质选项 | 开销大，不影响可读性 |
| SSAO | 开，强度适中 | 只做适度的接触暗部 |
| SSIL | 画质选项 | 间接光更自然，开销中等 |
| SDFGI | 不默认开 | 开销最大；按世界坐标分区，浮动原点平移时可能整片重算，实测后再定 |
| 辉光 | 开，只作用于发光体 | 灯具、屏幕等；不做全屏泛光 |
| 深度雾 | 开 | 远处和尚未建好的分段用雾收住（[01](../design/01-voxel-engine-and-scenes.md)、[07](../design/07-rendering.md)） |
| 体积雾 | 不用 | 天气在 Demo 之后 |
| 景深 | 不用 | 会遮住状态 |
| 自动曝光 | 不用 | 时段固定，曝光固定 |
| 屏幕空间反射 | 画质选项 | 场景中反光表面少；半透明玻璃在 Demo 之后 |
| 抗锯齿 | MSAA 4× | 立方体边缘和细钢轨容易锯齿；TAA 实测后再决定是否作为选项，跟随运动的列车上可能拖影 |
| 去色带 | 开 | 天空渐变不出现色带 |
| 贴花 | 不用 | 损伤和磨损用着色器叠加，标识在 Demo 之后，见 [06](06-wear-damage-and-motion.md#贴花) |

画质分“中”“高”两档：中档就是上表的默认画质，高档在中档上打开画质选项。

### 色调映射与颜色

- 色调映射用 AgX：高光过渡自然，亮色不偏色。
- 不做全局调色，不用风格化的颜色查找表。亮度、对比度、饱和度保持中性。
- “冷峻”靠工业材料的固有色体现，不给全屏染冷色；地貌和植被保留丰富的色彩（美术 Q228）。

### 光照与天空

- 以自然主义光照为基准（美术 Q227）。
- 太阳方向在世界中固定，不随相机转动。
- 环境光取自天空。
- 深度雾的颜色取地平线的天空色，让场景边界自然融进天空。

### 可读性

- 一列车先看整体轮廓，再看功能设备、承载和安装结构、材质分区，最后才是细小污痕和标识。远处看不清的小细节不能成为分辨车种的唯一依据。
- 长编组靠车体的连续和上装的节奏表现宏大，不需要每节车顶都装同样的设备，也不靠广角镜头夸张（美术 Q186）。
- 远处的贴图允许 Mipmap 和必要的过滤，运动中稳定优先于保持硬像素颗粒（美术 Q223）。

### 检查光照

资产须在中性日光、阴天、夜间人工照明三种检查光照下看得清形体和材质（美术 Q230）。这是制作和检查时的条件，不代表游戏里有这三种时段。检查在正常游戏窗口里，按 [08 检查清单](08-asset-pipeline-and-review.md#检查清单)的三种距离进行；切换方式见 [08](08-asset-pipeline-and-review.md#检查地点与检查光照)。

## 本阶段

首个切片的线路场景和最小节点场景：

- 固定白天时段，晴天，无云，用 Godot 的程序天空，环境光取自天空。
- 太阳为中性偏暖的白光，高度角 35–45°。
- 地平线天空和雾的颜色为 `#c9d6e0`，来自[首个切片场景资产样稿](../../archive/prototypes/first-slice-scene-assets.prototype.html)。
- 效果按默认画质。
- 没有昼夜变化和天气。

具体数值在[线路场景](https://github.com/odradekk/train/issues/229)实现时调。
