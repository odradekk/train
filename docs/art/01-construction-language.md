# 01 构造语言

> 决策出处：美术 Q181–Q188、Q191–Q207、Q209–Q213、Q215、Q224、Q234–Q239。形状怎样进入内容、自定义模型的贴图、严格内接与禁止缩放、复合体与大型设备、首个切片车头和货车的外形，由[非立方体形状与构造语言](https://github.com/odradekk/train/issues/245)于 2026-10-09 确认，美术 Q214 的 Blueprint Stamp 由该票取消；其余从[美术方向初稿](../research/art-direction-draft-2026-10-08.md)第 2–5 节改写。

## 边界

本文规定车辆、建筑和大型设备怎样由体素组成：用途与造型、重量感、尺度与子网格、形状、自定义模型、大型设备、接缝与倒角。占格、朝向和六面连通见设计文档 [01](../design/01-voxel-engine-and-scenes.md)，表现格式与校验见 [02](../design/02-definitions-and-content.md#表现资产校验)，档位尺寸、部件与结构见 [03](../design/03-vehicles-buildings-and-designs.md)，渲染路径和遮面见 [07](../design/07-rendering.md)，复合体嵌套的规则见设计文档 [03 的复合体嵌套](../design/03-vehicles-buildings-and-designs.md#复合体嵌套)；本文引用、不重述。贴图见 [02](02-materials-and-textures.md)，光照与可读性见 [05](05-lighting-and-readability.md)，地形、建筑和铁路的具体规格见 [04](04-world-assets.md)。

## 不变量

1. **构造一致。** 车辆、建筑和大型设备只由游戏中可获得的体素定义组成，没有开发者专属的外壳块或整车模型；可获得不等于开局全部拥有。地形和装饰这类场景体素不能放进车辆、建筑和大型设备，只用于场景模型和生物（美术 Q197、Q239）。
2. **形状不等于玩法。** 形状只决定外观；质量、耐久和能力来自体素定义，外观相似不等于数值相同（美术 Q201、Q236）。
3. **一格一块。** 一个体素占一整格。半块、薄板、管道和镂空框架都不能在格里余下的空间再放第二个体素（设计文档 01）。
4. **严格内接。** 形状和自定义模型完全位于自己的格内；会动的部分，运动范围也在格内。需要跨格的结构由多个体素组成，或走专用渲染（美术 Q212、Q238）。
5. **只用标准变体。** 不任意缩放、剪切或按自由角度旋转；朝向只取体素定义允许的正交朝向（美术 Q203–Q205）。
6. **视觉与合法性分开。** 模型在视觉上有没有接触，不影响设计是否合法；合法性只看六面相邻（美术 Q207，设计文档 01）。
7. **功能靠真实的设备轮廓读出。** 雷达、散热器、炮塔、储罐、吊装结构有各自的大轮廓，不只靠换色或贴图区分；外观本身不带来能力（美术 Q188）。

## 规则

### 用途与造型

造型由用途决定，尺寸只决定可用空间（美术 Q181）：

| 造型 | 特征 | 常见用途 |
| --- | --- | --- |
| A：铁路机车 | 驾驶室、检修走廊、散热、轮组和货运结构清楚，一看就是铁路车辆 | 民用运输、工程、工业服务 |
| B：装甲铁路车辆 | 仍然明显是列车，增加斜面车鼻、局部防护、窄观察窗和加强的安装结构 | 防护运输、护卫、军用通用车辆 |
| C：轨道移动设施 | 宽厚的船体式结构、大型设备、多功能上装和连续平台 | 重型战斗、指挥和特殊移动设施 |

民用通常偏 A、B，军用通常偏 B、C，但这不是硬性限制，也不按尺寸自动对应：可以有巨型的民用工厂车、采矿车，也可以有小而高度军事化的侦察车。

- 内置型号是起点：按用途装好基本设备，玩家和 AI 可以按同一套规则改装、加装和升级。官方型号不使用玩家无法复现的外形（美术 Q188、Q197）。
- 编组由玩家决定，可以全是泰坦，也可以混用各档或用更多小车；美术上不规定泰坦占比、车长或节数（美术 Q187）。

### 重量感

- **轮组半暴露。** 能看出车轮、转向架、牵引和制动结构的分组，允许局部护板；不能把行走机构完全遮平，让车体像悬浮的盒子，也不要求每根小管线都单独做出来（美术 Q182）。
- **装甲是可替换的结构。** 装甲是结构体素，靠斜面、切角、板厚和安装关系表现，不靠满车的细螺丝；没有功能性 Behavior 的装甲不因外观像设备而成为部件（美术 Q183）。装甲和设备共存只有两种做法：在相邻格放真实的外围装甲，或选用同一格内已集成防护的另一种设备型号；不允许同一格放两个体素，也不免费附加隐藏装甲（美术 Q213）。
- **武器安装。** 以现实工程的延伸为主，允许少量近未来技术（美术 Q184）。安装方式有炮塔式、嵌入式（炮廓）和垂直模块式三类；这只是外观分类，不规定射界、瞄准或伤害（美术 Q185）。
- **泰坦与长编组。** 泰坦强调长、宽、重和横向延展，不靠一直向上堆高。单节有稳定的主轮廓，多节连起来时靠上装的功能差异和重复结构形成节奏（美术 Q186）。方向见[长编组参考图](../../archive/prototypes/art-reference-v1/images/concept-titan-convoy.webp)，图中的车体比例和炮塔大小不是规格。

### 尺度与子网格

| 尺度 | 规则 | 不代表 |
| --- | --- | --- |
| 体素格 | 边长 0.5 米，一格一个体素（设计文档 01）；人物约 3 格高 | 一格必须由完整立方体填满 |
| 子网格 | 建模时参考 1/8 格，大形优先用 1/2、1/4、1/8 的比例（美术 Q192） | 新的占格单位，或可以单独受损的小格 |

- 车辆尺寸见设计文档 [03 的五档尺寸](../design/03-vehicles-buildings-and-designs.md#五档尺寸)，建筑按地块尺寸，本文不另列尺寸表。
- 归档原型中的 T-24、C-16、D-24 是实验用的样机，尺寸不是规格。移植时按现行尺寸重新布局，不能整体缩放后还声称每块占一格。
- 子网格不是硬性的顶点吸附：圆周上的顶点、局部倒角和必要的小细节可以不落在 1/8 格点上，但整体外形、接口和比例保持一致，也不越出所在的格。

### 形状

- 形状是游戏内置的几何外形。体素定义的立方体表现用 `shapes` 列出允许的形状和标准变体，设计的每一格放置时从中选一种，不选时用列表的第一项（[Demo 内容与资产清单：覆盖场景与制作验收](https://github.com/odradekk/train/issues/283)，2026-10-10），格式见设计文档 [02](../design/02-definitions-and-content.md#表现资产校验)，渲染见 [07](../design/07-rendering.md#cube-voxel-rendering)。新增形状要改代码；Mod 需要新外形时用自定义模型。
- 基础几何由开发工具按参数生成，游戏只发布有限、经过校验的标准变体（美术 Q209、Q235）。
- 首批形状按下表的顺序制作（美术 Q234）。P0、P1、P2 是制作先后，不是科技等级、稀有度或强度；没有样机用到的形状不必提前做（美术 Q210）。

  | 顺序 | 形状 | 用途 |
  | --- | --- | --- |
  | P0 | 立方体 | 连续主体、填充、墙体和基础结构 |
  | P0 | 半块 | 平台、分层外壳、半厚结构 |
  | P0 | 薄板 | 装甲表层、护板、轻薄外壳 |
  | P0 | 楔形 | 斜面车鼻、装甲、屋顶和过渡 |
  | P0 | 角楔 | 转角和复合斜面的衔接 |
  | P0 | 梁 | 车架、支撑、梁柱 |
  | P0 | 圆柱 | 轴、罐体片段、圆形设备的基础 |
  | P1 | 四分之一块 | 补充分层厚度 |
  | P1 | 切角块 | 工业外壳和边缘处理 |
  | P1 | 框架 | 开放结构、门框、设备固定架 |
  | P1 | 直管 | 标准管线段 |
  | P1 | 弯管 | 管线转角 |
  | P2 | 球体 | 特殊设备或圆形外壳 |
  | P2 | 锥体 | 锥形罩、渐缩接头和特殊设备 |

- 标准厚度为 1、1/2、1/4、1/8 格（美术 Q202）。这是预制的变体，不要求每种形状都做全四档，也不允许同一格叠放几块薄板。
- 半块、薄板等贴面形状默认贴着格的一面，靠正交朝向复用，不为上下左右各做一份（美术 Q211）。
- 斜面用标准楔形、角楔、切角和固定比例的过渡件，接头用标准直段和转角（美术 Q194、Q205）。
- 圆柱、车轮、管道和圆形设备用低面数曲面，8、12、16 边作为不同尺寸的起点，不是全库统一的面数。不为“体素风”把圆做成阶梯，也不为“写实”把曲面细分到接近 CAD 的光滑（美术 Q193）。
- 同一种形状可以给多种体素定义使用，同一种体素也可以放成多种形状（楔形结构块和立方体结构块是同一种货物），但不批量生成“所有形状 × 所有材料”的组合（美术 Q236）。
- 形状沿用体素定义的面贴图，见 [02](02-materials-and-textures.md#形状与自定义模型)。

### 自定义模型

- 门窗、散热器、灯具、接口、机械外壳和武器部件等有专门细节的体素用自定义模型，在 Blender 中制作（美术 Q209）。自定义模型同样严格内接、只取正交朝向、按原尺寸使用，贴图见 [02](02-materials-and-textures.md#形状与自定义模型)。
- 拆分按玩法需要：需要单独安装、替换、损伤或有行为的部分做成独立的体素；小螺栓、细小接口、格栅条等纯细节做进模型里（美术 Q215、Q237）。
- 先复用已有的体素定义和形状，必要时再新增专用的体素定义；新增的同样在游戏中可获得（美术 Q239）。

### 大型设备

- 跨多格的大型雷达、多格炮塔、发电舱和大型安装架是大型设备。大型设备是复合体，由多个体素组成，有自己的蓝图，装在车辆、建筑或另一件大型设备上，可以整体转动和替换，拆下后可以入库。嵌套、转动、拆装和编辑器操作的规则见设计文档 [03 的复合体嵌套](../design/03-vehicles-buildings-and-designs.md#复合体嵌套)。
- 安装座、支架和接口要标准化、看得出来；这不引入新的物理接口系统（美术 Q199）。
- 复杂外形优先由简单、清楚的大形组合出来，不靠把每个螺丝做成体素，也不靠单个超复杂的整体模型（美术 Q200）。
- 组装的大型设备（例如炮塔）能力由其中的部件相加；大型柴油机、多格火炮这类功能复合体整件提供能力，由内容包提供，玩家不能改它的体素（设计文档 [03](../design/03-vehicles-buildings-and-designs.md#部件与结构)）。能力只来自行为，外观本身不带来能力。

### 接缝与倒角

模块边界可读，但不刻意强调：远看整体轮廓和用途，近看才读出装配关系；不沿每个格画黑线，不把一面连续的墙做成棋盘格（美术 Q196）。

| 结构 | 接缝处理 |
| --- | --- |
| 连续的地形、墙体和大块混凝土 | 不显出每格的边界，保持连续 |
| 可拆的装甲、检修板和设备接口 | 用真实的板厚、局部缝隙、材料变化和安装结构表达 |
| 梁、框架和管线 | 靠实际的端部、标准接头和结构连接表达 |
| 模型内部的小细节 | 服从主轮廓，不为每条细缝做强对比 |

- 只有立方体时，接缝画在贴图上，见 [02 的贴图画法](02-materials-and-textures.md#贴图画法)（美术 Q206）。
- 倒角按类别控制：地形用的立方体保持锐利，混凝土克制，机械外壳适量，重型装甲可以用明显的切角。不能把每块都缩小再倒角，造成满车漏缝或塑料积木感。倒角可以小于子网格，但仍须内接，并在实际屏幕尺寸下检查（美术 Q224）。
- 两个体素六面相邻、但模型在视觉上没有接触时，以后由编辑器提示，不阻止发布（设计文档 [15](../design/15-design-editor-and-tools.md#demo-之后)）。
- 遮面看视觉上是否完全遮住，不看占格：半块、框架、圆柱和镂空材质占了整格，也不一定盖住邻面，见设计文档 [07](../design/07-rendering.md#cube-voxel-rendering)。
- 不用全局黑色描边，AO 适度，见 [05](05-lighting-and-readability.md#不变量)。

## 本阶段

首个切片只有立方体，小型车头和小型货车（52×7×9 格）按下面的外形制作。体素的数值和布局由[设计并实现首个切片的货物、聚居地类型与预置蓝图](https://github.com/odradekk/train/issues/236)编写，素材由[补齐首个切片的货物与车辆体素素材](https://github.com/odradekk/train/issues/234)制作，面贴图规格由[首个切片的体素面贴图规格](https://github.com/odradekk/train/issues/246)编写。

- 车窗带靠控制部件的侧面图画出车窗。正面图不平铺，驾驶室前脸不用正面图，否则同一张图会在 7×6 格的前脸上重复 42 次。
- 斜面车鼻属于 B 类，首个切片不用。
