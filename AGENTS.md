## Current phase: MVP validation

- Optimize for learning speed: choose the smallest playable change that tests the current core-gameplay assumption.
- Work in short iterations and validate each one before expanding scope.
- Keep architecture, abstractions, content, polish, and future extensibility proportional to the current test; defer anything that does not directly improve the validation result.
- Stop when the current question has enough evidence to decide the next small step.
