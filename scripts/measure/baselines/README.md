# 性能基线索引

这里按三个守护操作列出已提交的 Linux runner 历史汇总，供观察长期变化；不同构建、输入或统计定义的数字不能直接作为改前改后对照，也不代表当前性能达标。

各操作汇总的构建、输入和环境章节记录提交号、工作树状态、内容版本、机器、电源、运行时版本及外部负载；统计章节说明轮数、中位数、范围及汇总方法。原始数据与复算方法见各文件末节，基线规则见 [App/Measurement/AGENTS.md](../../../App/Measurement/AGENTS.md)。
