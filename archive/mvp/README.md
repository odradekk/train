# MVP archive

This directory preserves the prototypes, specification-era Godot implementation, tests, and reproducible configuration used to validate the automated trade loop.

It is historical evidence, not the current production project. New game development belongs at the repository root. Copy or rewrite only the specific archived code needed by a selected gameplay slice.

Generated Godot state, restored packages, test output, and Windows builds are intentionally excluded. From `archive/mvp/godot`, use the pinned SDK and committed export configuration to reproduce them when needed.
