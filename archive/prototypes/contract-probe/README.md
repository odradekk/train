# 四模块契约调用原型

本目录回答[契约原型：验证四模块能独立调用与替换](https://github.com/odradekk/train/issues/292)的规划问题。输入为 `8636b68` 的公开契约和调用样例；这里的程序可抛弃，不是四模块生产实现，也没有将生产测试入口或 CI 改成这套脚本。正式验证组织仍见[四模块独立构建与契约验证](../../../docs/contracts/testing.md)。

在 Windows、PowerShell 7、锁定 .NET SDK 和 Godot .NET 4.7.2／Windows 导出模板齐备的环境，从仓库根执行：

```powershell
pwsh -NoProfile -File archive/prototypes/contract-probe/Run.ps1
```

命令新建 `TestResults/run-tests/contract-probe-<时间>/`，保留 `summary.json`、`report.md`、输入哈希、隔离路径、实际项目／程序集依赖及原始日志。它依次调用四个可单独运行的原型入口；不读取其他模块的生产内部实现，不复制已有构建产物。失败保留证据并返回非零。原型源码和正在使用的旧消费样例分开，真实 Godot 使用同一份消费样例构建。

## 六条路径的证据边界

| 路径 | 本原型验证什么 | 仍需真实实现验证什么 |
| --- | --- | --- |
| 内容投影到核心输入 | 仅凭契约构造固定设计，蓝图保存后随建造／立即应用命令提交；强类型流程输入可消费 | 解析、设计计算、改装差额、缺失内容与业务合法性 |
| 命令、快照、事件到场景 | 接受／拒绝／故障可区分；固定视图和嵌套值保留；场景样例取得并展示同一帧、按实际帧拾取 | 模拟裁决、战斗事件资料、几何生成和拾取、人口／市场续接 |
| 场景与资产到 Godot | 真实 PNG 纹理、固定 GLB 字节到模型、ArrayMesh 上传、绕序及坐标；Keep File 原字节进入 PCK，在源运行和 Windows 导出运行验证 | 完整检查器及结构矩阵、整帧资源原子安装、共享资源退役、真实渲染观感与性能 |
| 编辑草稿到校验与提交 | 固定情景下编辑锁、拒绝、不同时机的评估／保存修订、递归集合内容比较和只读图标预览入口 | 完整布局操作、撤销重做、合法性与各类别设计计算 |
| 读档、发布、切换 | 候选失败不激活；同步核心裁决控制内容激活；模板副本关联顺序；同一输入身份的多设计视图保留；真实文件占用、部分写入及替换边界 | 完整容器往返、生产内容恢复和重启诊断、真实核心录制编码与严格重放算法、活动组停用 |
| 异步完成 | 可控的 A 取消／B 重开／A 晚回；B 的身份和脏标记保留，A 释放；迟到评估和保存不误配 | 实际后台工作退出、真实宿主取消与资源生命周期 |

固定数据与脚本替身没有重写经济、模拟、设计计算或网格算法。生产者尚未按新契约迁移，因此尚不能让真实生产者与替身共同运行全部断言。核心固定录制／重放情景只用于检查公开交接和边界，不把预置结果当作真实重放算法。各原型的具体支持范围见 [Core](Core/README.md)、[Content](Content/README.md)、[Scenes](Scenes/README.md) 和 [Godot](Godot/README.md)。

## 违规必须被检出

| 故意违规 | 检查机制 |
| --- | --- |
| 真正编译的禁止程序集依赖 | MSBuild 解析路径和 PE AssemblyReference 允许范围 |
| 公开接口新增必填参数 | 基于实际程序集的公开符号差异，同时使原调用样例编译失败 |
| 拒绝之前改变活动内容 | 同一个协调前后状态断言 |
| 已取消旧请求覆盖新会话 | 确定完成顺序的状态与释放断言 |
| 后续更新修改已返回快照的嵌套数组 | 同一份快照保留断言 |

每种违规都有正确、明确失败和恢复通过的证据；工具未启动或不相关编译错误不算检出。公开面观察文件是本次运行的比较输入，**不是已批准的整组契约基线**。尚不存在的生产创建工厂没有参与符号位置检查；生产实现依赖和隔离装配、统一入口与 CI 接入仍按后续实施任务交付。

## 结论的使用

本原型可判断公开契约是否足以编写消费方、构造有限情景，并检查约定中的代表性违规。不能据此关闭完整 Demo 的实现／验收项，不能用纯替身补齐真实文件、引擎或业务证据。人口周期与冻结规则、市场计时／租约／报告、真实内容重载及缺失引用恢复等没有重复实现，保留为相应生产模块的必验情景。

用户已确认[本票结论](https://github.com/odradekk/train/issues/292#issuecomment-6098600280)，原型归档于本目录。归档只调整目录、运行入口和相对引用，不改变验证情景；原始调用样例继续位于 `prototypes/*-contract/`。本目录不建立正式契约基线，后续实施仍须完成上述真实模块验证。
